C-RO

Kit CSS/JS no estilo da interface do Classic Ragnarok Online (2002), sobre o Bootstrap 5.3.8. Escreva o Bootstrap de sempre; a página sai com o visual do jogo.

Documentação

  • Para pessoas (com exemplos renderizados): https://kevencastilho.github.io/C-RO_WebKit/docs/index.html
  • Para IAs (HTML puro, uma página por assunto): https://kevencastilho.github.io/C-RO_WebKit/docs/ai/index.html
  • Para IAs, uma página só com o essencial: https://kevencastilho.github.io/C-RO_WebKit/docs/ai/essentials.html
  • Para IAs, em texto: https://kevencastilho.github.io/C-RO_WebKit/docs/ai/ai-essentials.txt (curto) e https://kevencastilho.github.io/C-RO_WebKit/docs/ai/ai-full.txt (tudo)
  • Navegação em JSON: https://kevencastilho.github.io/C-RO_WebKit/docs/ai/nav.json
