    Extras do kit

    Cursores do Ragnarok

    Extra do kit

    Todo o site passa a usar os cursores do Ragnarok Online — seta, mão, balão de ajuda, relógio, redimensionar... — inclusive animados. Sem classe, sem configuração.

    O que acontece ao incluir o kit#

    • A seta do Ragnarok vira o cursor padrão da página.
    • Cada estado nativo do CSS (pointer, help, wait, move, not-allowed, ns-resize...) ganha o cursor do jogo. Os cursor: do próprio Bootstrap e do kit são convertidos no build.
    • O JS do bundle anima o cursor que está sob o ponteiro (a seta gira, o balão abre, a porta de warp roda).
    • Há cursores extras aplicados por contexto, como a mão com "?" em tooltips. Veja Estados automáticos.

    Usar um cursor do Ragnarok no seu CSS#

    Cada estado é uma variável --cro-cur-<nome>. Use var(), e não a palavra-chave, para ter o cursor do jogo:

    CSS
    .minha-area  { cursor: var(--cro-cur-ro-attack); }  /* espada */
.meu-botao   { cursor: var(--cro-cur-pointer); }    /* mão do Ragnarok */
.cantos      { cursor: var(--cro-cur-nwse-resize); }
    espada (ro-attack)
    alvo (ro-target)
    warp (ro-warp)
    lock (ro-lock)
    HTML
    <div class="bd-demo-box" style="cursor:var(--cro-cur-ro-attack);width:150px">
  espada (ro-attack)
</div>
<div class="bd-demo-box" style="cursor:var(--cro-cur-ro-target);width:150px">
  alvo (ro-target)
</div>
<div class="bd-demo-box" style="cursor:var(--cro-cur-ro-warp);width:150px">warp (ro-warp)</div>
<div class="bd-demo-box" style="cursor:var(--cro-cur-ro-lock);width:150px">lock (ro-lock)</div>

    Seu cursor sempre vence#

    Todas as regras do kit têm especificidade zero (:where()). Qualquer cursor que você declare prevalece, por exemplo para cursores de outro tema.

    Atenção

    Se você escrever a palavra-chave (cursor: pointer), o navegador mostra o cursor nativo. Para o cursor do Ragnarok, use var(--cro-cur-pointer).

    Animação#

    Controle Efeito
    (padrão) Anima só o estado sob o ponteiro
    <html data-cro-cursor-anim="off"> Desliga a animação (fica no quadro de repouso)
    prefers-reduced-motion: reduce Desliga sozinho
    Aba oculta / ponteiro fora da janela Pausa

    O CSS não consegue animar cursor; por isso o JS troca o valor dos tokens em <html>. Sem JS, o cursor continua correto, só estático.

    Origem#

    • Original: seta, mão, balão, lock, rotate, attack, warp e target vêm do cursors.spr/cursors.act do jogo (fonte da verdade). Tamanhos 1:1 com o jogo.
    • Derivado: relógio, redimensionar, mover e as mãos extras vêm de pacotes de cursores de terceiros (preenchem o que o jogo não tem). A licença desses arquivos ainda não foi confirmada.
    • Inventado: copy, alias, context-menu, cell, zoom e a barra I foram desenhados no estilo dos sprites.
    Limitação

    Cursores acima de ~32px podem ser reduzidos por alguns sistemas; os navegadores ignoram imagens acima de ~128px. A barra de rolagem nativa, popups de select e a UI do navegador mantêm o cursor do sistema.
