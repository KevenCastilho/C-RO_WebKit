    Extras do kit

    Tokens (variáveis CSS)

    Extra do kit

    Os valores de cor, medida e fonte do kit, expostos como variáveis --cro-* em :root.

    Como usar#

    CSS
    :root { --cro-accent: #a01a8c; }          /* global */
.minha-area { --cro-field-bg: #fff6cc; }   /* só dentro desta área */
.cro-window { filter: var(--cro-win-drop); }

    Cada token traz a origem: CONFIRMADO (medido nos bitmaps do jogo), DERIVADO (deduzido de forma documentada) ou INVENTADO.

    Atenção

    Os sprites (botões, barras, ícones, abas) são imagens de CSS e não seguem os tokens de cor. Os tokens afetam cores, fontes e medidas lidas com var(): acento, seleção, campos, corpo de janela, fonte, sombra, texto desabilitado, entre outros. Veja Customização.
