    Começando

    JavaScript

    Guia

    O bundle c-ro-bs.js traz o JavaScript do Bootstrap e o do kit. Tudo é opcional — o visual é só CSS.

    O que o bundle traz#

    c-ro-bs.min.js contém, nesta ordem, o Bootstrap 5.3.8 (bundle com Popper) e o JS do kit. Ele cria window.bootstrap e window.CRO. Sem dependências (sem jQuery).

    Parte Faz
    Bootstrap Modal, dropdown, tooltip, popover, collapse, carousel, toast, offcanvas, scrollspy, abas... (atributos data-bs-* e API new bootstrap.X())
    CRO.init() Liga abas data-cro-tabs e selects data-cro-select (roda sozinho no load)
    CRO.alert/confirm/prompt/menu Diálogos e menu de contexto no visual do jogo — veja Diálogos
    Cursor animado Anima o cursor do Ragnarok sob o ponteiro — veja Cursores
    Favicon Aplica o favicon do kit se o site não tiver um — veja Favicon

    Atributos data-* do Bootstrap#

    Funcionam como no Bootstrap, sem JavaScript seu:

    Janela

    Comportamento do Bootstrap, visual do jogo.
    Conteúdo recolhível.
    HTML
    <button class="btn btn-secondary" data-bs-toggle="modal" data-bs-target="#jsModal">
  Abrir modal
</button>
<button class="btn btn-secondary" data-bs-toggle="collapse" data-bs-target="#jsCol">
  Alternar collapse
</button>
<div class="modal fade" id="jsModal" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content">
      <div class="modal-header">
        <h1 class="modal-title fs-5">Janela</h1>
        <button
          type="button"
          class="btn-close"
          data-bs-dismiss="modal"
          aria-label="Fechar"></button>
      </div>
      <div class="modal-body">Comportamento do Bootstrap, visual do jogo.</div>
    </div>
  </div>
</div>
<div class="collapse w-100" id="jsCol">
  <div class="card card-body">Conteúdo recolhível.</div>
</div>

    Tooltips, popovers e toasts#

    Tooltips e popovers precisam ser inicializados (como no Bootstrap). Toasts também:

    Avisoagora
    Toast com barra de título.
    HTML
    <button class="btn btn-secondary" id="tt1" data-bs-toggle="tooltip" data-bs-title="Dica do kit">
  Passe o mouse
</button>
<button
  class="btn btn-secondary"
  id="tt2"
  data-bs-toggle="popover"
  data-bs-title="Título"
  data-bs-content="Conteúdo do popover">
  Popover
</button>
<button class="btn btn-secondary" id="tt3">Mostrar toast</button>
<div class="toast-container position-fixed bottom-0 end-0 p-3">
  <div id="tt4" class="toast" role="alert">
    <div class="toast-header">
      <strong class="me-auto">Aviso</strong>
      <small>agora</small>
      <button
        type="button"
        class="btn-close"
        data-bs-dismiss="toast"
        aria-label="Fechar"></button>
    </div>
    <div class="toast-body">Toast com barra de título.</div>
  </div>
</div>
    JS
    // tooltips e popovers: a documentação já liga os deste exemplo; no seu site faça:
document.querySelectorAll('[data-bs-toggle="tooltip"]').forEach(function (el) {
  new bootstrap.Tooltip(el);
});
document.querySelectorAll('[data-bs-toggle="popover"]').forEach(function (el) {
  new bootstrap.Popover(el);
});
document.getElementById('tt3').addEventListener('click', function () {
  bootstrap.Toast.getOrCreateInstance(document.getElementById('tt4')).show();
});

    API do kit (window.CRO)#

    API Retorno Uso
    CRO.init(root?) — Liga abas e selects dentro de root (idempotente). Chame depois de inserir HTML novo.
    CRO.alert(msg, {title, ok}) Promise<undefined> Aviso
    CRO.confirm(msg, {title, ok, cancel}) Promise<boolean> Confirmação (Esc = false)
    CRO.prompt(msg, padrão, {title, ok, cancel}) Promise<string \| null> Entrada de texto (Esc/Cancelar = null)
    CRO.menu(itens, x, y) Promise<value \| undefined> Menu de contexto; setas/Enter/Esc
    CRO.bar(el, perc) — Define a largura de uma barra HP/SP e troca para vermelha abaixo de 25%
    HTML
    <button class="btn btn-secondary" id="b-alert">CRO.alert</button>
<button class="btn btn-secondary" id="b-conf">CRO.confirm</button>
<button class="btn btn-secondary" id="b-prompt">CRO.prompt</button>
<span id="b-out" class="ms-2"></span>
    JS
    var out = document.getElementById('b-out');
document.getElementById('b-alert').onclick = function () {
  CRO.alert('Olá, aventureiro!').then(function () { out.textContent = 'alert fechado'; });
};
document.getElementById('b-conf').onclick = function () {
  CRO.confirm('Sair do jogo?').then(function (v) { out.textContent = 'confirm: ' + v; });
};
document.getElementById('b-prompt').onclick = function () {
  CRO.prompt('Nome do personagem:', 'Ana').then(function (v) {
    out.textContent = 'prompt: ' + JSON.stringify(v);
  });
};

    Só o kit, sem Bootstrap#

    Com c-ro.js você tem CRO.*, abas data-cro-tabs, select, cursor e favicon, mas não bootstrap. Veja Download.

    Limitação

    datalist e os seletores nativos de data e cor continuam nativos: o CSS não consegue estilizar o popup deles.

    Funções internas expostas#

    Além das APIs acima, window.CRO expõe duas funções de abas:

    API Uso
    CRO.initTabs(root?) Liga só as abas data-cro-tabs dentro de root (o CRO.init chama esta e a do select)
    CRO.selectTab(botao, focar?) Ativa a aba do botao por código (focar = true move o foco)
    JS
    CRO.selectTab(document.querySelector('[data-cro-tab="2"]'), true);
