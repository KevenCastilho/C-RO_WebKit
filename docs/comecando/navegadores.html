    Navegadores e limites

    Guia

    O que o kit exige do navegador e o que, por decisão ou por limite técnico, ele não faz.

    Suporte#

    O kit usa recursos modernos de CSS, principalmente @layer, :where(), :is(), mask, container-type e imagens data: em cursor/background.

    Navegador Versão mínima (aprox.)
    Chrome / Edge 120+
    Firefox 110+
    Safari 16+
    Nota

    Versões aproximadas. A fidelidade dos testes automáticos é feita em Chromium. Navegadores sem @layer (anteriores a 2022) não são suportados.

    Decisões de escopo#

    • RTL: não suportado. A interface do Ragnarok não é RTL; suportar quebraria o visual do kit. O dir="rtl" do Bootstrap não é adaptado.
    • Modo escuro: fora da v1. O jogo é claro. A ideia fica para depois que a primeira versão estiver estável.

    Limites técnicos (UI que o CSS não alcança)#

    Elemento O que acontece Alternativa
    Popup do <select> Nativo <select data-cro-select> usa popup do kit
    <datalist> Nativo —
    Seletores de data, hora e cor (popup) Nativos —
    Barras de rolagem Visual do jogo só em motores WebKit/Blink Firefox usa rolagem nativa
    Tooltip Sem seta (limitação do desenho do jogo) —
    Cursor Imagens de até ~128px; acima disso o navegador ignora Já respeitado pelo kit
    Menu de contexto do sistema, barra de título da janela Nativos —

    Cursores e favicon dependem de JS?#

    • O cursor estático é só CSS. A animação do cursor precisa do JS do bundle (CSS não anima cursor).
    • O favicon automático precisa do JS do bundle.

    Movimento reduzido#

    Com prefers-reduced-motion: reduce, o cursor deixa de animar (fica no quadro de repouso). Os componentes do Bootstrap respeitam a mesma preferência.
