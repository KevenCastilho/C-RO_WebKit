    Para IAs

    Guia

    Existe uma versão desta documentação feita para agentes de IA. Se você pediu para uma IA conhecer, estudar ou usar o C-RO, mande ela para lá.

    Por que uma versão separada#

    Esta documentação foi feita para pessoas: tem exemplos renderizados, navegação lateral e busca. Uma IA lê melhor uma página limpa, sem esse aparato, com as regras do kit logo no começo e cada assunto numa página pequena e autossuficiente. É isso que a versão para IAs entrega.

    Abrir a documentação para IAs

    Ela é gerada a partir desta mesma documentação, então não fica desatualizada em relação a ela. O texto de apresentação está em inglês; a prosa das páginas segue em português, e o código e os nomes de classes não dependem de idioma.

    Como pedir para uma IA usar o C-RO#

    Cole este texto na conversa e troque a última frase pela sua tarefa. A IA precisa conseguir abrir links; se ela não puder, use o link acima e cole o conteúdo das páginas que importam.

    TEXT
    Read https://kevencastilho.github.io/C-RO_WebKit/docs/ai/index.html first,
then the pages it points to for what I ask.
Use only what that reference documents (classes, tokens,
data attributes, JS API); if something is not documented there,
say so instead of guessing.
My task: <describe what you want to build or understand>.
    Dica

    Para tarefas pequenas basta a página Essentials: ela reúne arquivos, página mínima, regras, API de JavaScript e limites.

    O que a IA encontra lá#

    • Index: mapa por tarefa (modal, formulário, abas, cursores...) e a lista de todas as páginas.
    • Essentials: o que carregar e as regras que evitam os erros mais comuns.
    • Uma página por assunto, com tipo (Bootstrap puro, peça nativa, extra), as classes cro-* usadas, o link para a versão humana e todos os exemplos de código.
    Limitação

    Não sei dizer quais ferramentas de IA abrem links sozinhas ou seguem o redirecionamento desta página. Em caso de dúvida, passe a URL direta de ai/index.html.
