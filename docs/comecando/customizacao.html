    Começando

    Customização

    Guia

    Como mudar o visual do kit sem editar o kit — tokens (variáveis CSS), seu próprio CSS e a troca da fonte.

    Dois níveis#

    Nível Quando usar Como
    1. Tokens --cro-* Trocar cor de destaque, seleção, fundo de campo, fonte... Redefina a variável em :root ou em qualquer container
    2. Seu CSS Ajustar um componente Escreva a regra; ela vence o kit (veja abaixo)

    1. Tokens#

    Os tokens ficam em :root e valem em qualquer escopo, inclusive dentro de um único componente. Veja a lista em Tokens.

    Padrão

    link com a cor de destaque

    Tokens trocados neste bloco

    link com a cor de destaque
    HTML
    <div class="d-flex flex-wrap gap-3 align-items-start">
  <div>
    <p class="mb-1"><b>Padrão</b></p>
    <input class="form-control mb-2" value="campo" style="width:160px">
    <a href="#">link com a cor de destaque</a>
  </div>
  <div style="--cro-accent:#a01a8c; --cro-field-bg:#fff6cc; --cro-field-border:#a01a8c">
    <p class="mb-1"><b>Tokens trocados neste bloco</b></p>
    <input class="form-control mb-2" value="campo" style="width:160px">
    <a href="#">link com a cor de destaque</a>
  </div>
</div>
    CSS
    :root {
  --cro-accent: #174888;      /* links, rótulos, destaque */
  --cro-sel-bg: #83a2ff;      /* item selecionado (lista, menu, tabela) */
  --cro-field-bg: #f2f2f2;    /* fundo dos campos */
  --cro-field-border: #c0c0c0;
  --cro-win-body: #ffffff;    /* corpo de janela/card/modal */
  --cro-font-ui: "Minha Fonte", Helvetica, Arial, sans-serif;
}
    Atenção

    Os sprites do kit (botões, barras, ícones, abas) são imagens de CSS pixel a pixel e não seguem tokens de cor. Os tokens mexem em cores, fontes e medidas que o kit lê via var(). Para mudar um sprite use o nível 3.

    2. Seu próprio CSS#

    O CSS do kit está fora do layer do Bootstrap e os elementos HTML nus usam :where() (especificidade 0). Resultado:

    • Uma regra sua, mesmo simples (button { ... }), vence o estilo de elemento do kit.
    • Para vencer uma classe do kit (.cro-btn, .btn), use um seletor de especificidade igual ou maior, ou carregue o seu CSS depois.
    • Qualquer cursor declarado por você vence o cursor do kit (veja Cursores).
    CSS
    /* seu CSS, carregado depois de c-ro-bs.min.css */
a { color: #0a5; }                 /* vence o kit: seletor de elemento */
.card-header { font-size: 14px; }  /* vence o Bootstrap (layer) e iguala o kit */

    Cores do tema Bootstrap#

    As cores contextuais do Bootstrap já vêm tematizadas (a paleta é a do jogo):

    Tema Cor Origem
    primary #174888 derivado do azul do jogo
    secondary #6e6e6e derivado
    success #1f6b2f derivado
    info #0f6a78 derivado
    warning #f3c34d derivado
    danger #8a1c1c derivado
    light / dark #f4f4f4 / #1f242c derivado

    Essas cores são compiladas no Bootstrap e não são tokens de runtime. Para usar outra cor, escreva o seu CSS: ele vence o kit.

    Fonte#

    Troque --cro-font-ui e --cro-font-title e carregue a sua fonte com @font-face. Lembre-se da licença da fonte nova.
