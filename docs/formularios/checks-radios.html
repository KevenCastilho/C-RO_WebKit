    Checks e radios

    Drop-in Bootstrap

    Checkbox, radio e switch com os indicadores do jogo.

    Checkboxes#

    HTML
    <div class="form-check">
  <input class="form-check-input" type="checkbox" id="ck1" checked>
  <label class="form-check-label" for="ck1">Marcado</label>
</div>
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="ck2">
  <label class="form-check-label" for="ck2">Desmarcado</label>
</div>
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="ck3" disabled>
  <label class="form-check-label" for="ck3">Desabilitado</label>
</div>
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="ck4">
  <label class="form-check-label" for="ck4">Indeterminado</label>
</div>
    JS
    document.getElementById('ck4').indeterminate = true;

    Radios#

    HTML
    <div class="form-check">
  <input class="form-check-input" type="radio" name="rd" id="rd1" checked>
  <label class="form-check-label" for="rd1">Opção 1</label>
</div>
<div class="form-check">
  <input class="form-check-input" type="radio" name="rd" id="rd2">
  <label class="form-check-label" for="rd2">Opção 2</label>
</div>

    Switch#

    HTML
    <div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" role="switch" id="sw1" checked>
  <label class="form-check-label" for="sw1">Efeitos sonoros</label>
</div>
<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" role="switch" id="sw2">
  <label class="form-check-label" for="sw2">Música</label>
</div>

    Em linha#

    HTML
    <div class="form-check form-check-inline">
  <input class="form-check-input" type="checkbox" id="in1">
  <label class="form-check-label" for="in1">A</label>
</div>
<div class="form-check form-check-inline">
  <input class="form-check-input" type="checkbox" id="in2">
  <label class="form-check-label" for="in2">B</label>
</div>

    Botões como checks#

    HTML
    <input type="checkbox" class="btn-check" id="btn-c1" autocomplete="off">
<label class="btn btn-outline-primary" for="btn-c1">Alternar</label>
<input type="radio" class="btn-check" name="btnr" id="btn-r1" autocomplete="off" checked>
<label class="btn btn-outline-primary" for="btn-r1">Um</label>
<input type="radio" class="btn-check" name="btnr" id="btn-r2" autocomplete="off">
<label class="btn btn-outline-primary" for="btn-r2">Dois</label>
    Nota

    Versão nativa: <label class="cro-check"><input type="checkbox"> Texto</label>. Veja Formulários cro-*.
