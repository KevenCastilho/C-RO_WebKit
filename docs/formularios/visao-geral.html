    Formulários

    Visão geral

    Drop-in Bootstrap

    Todos os controles de formulário do Bootstrap com o visual de campo do jogo: fundo cinza-claro, borda fina, rótulos azuis.

    Exemplo#

    HTML
    <form style="max-width:420px">
  <div class="mb-2">
    <label for="vg-email" class="form-label">E-mail</label>
    <input type="email" class="form-control" id="vg-email" placeholder="nome@exemplo.com">
  </div>
  <div class="mb-2">
    <label for="vg-sel" class="form-label">Classe</label>
    <select id="vg-sel" class="form-select">
      <option>Espadachim</option>
      <option>Mago</option>
      <option>Gatuno</option>
    </select>
  </div>
  <div class="mb-2">
    <label for="vg-msg" class="form-label">Mensagem</label>
    <textarea class="form-control" id="vg-msg" rows="2"></textarea>
  </div>
  <div class="form-check mb-2">
    <input class="form-check-input" type="checkbox" id="vg-ck" checked>
    <label class="form-check-label" for="vg-ck">Lembrar de mim</label>
  </div>
  <button class="btn btn-primary" type="submit">Enviar</button>
</form>

    Dois jeitos de escrever#

    1. Bootstrap: form-control, form-select, form-check-input...
    2. Nativo do kit: cro-input, cro-select, cro-textarea, cro-check, cro-field, cro-label. Veja Formulários cro-*.
    3. Elementos nus: sem classe nenhuma, o <input> já sai estilizado (Reboot).

    Tipos de input#

    HTML
    <div class="row g-2">
  <div class="col-md-4">
    <label class="form-label" for="t-text">Texto</label>
    <input id="t-text" class="form-control" value="valor">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-pw">Senha</label>
    <input id="t-pw" type="password" class="form-control" value="segredo">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-num">Número</label>
    <input id="t-num" type="number" class="form-control" value="42">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-date">Data</label>
    <input id="t-date" type="date" class="form-control" value="2026-10-08">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-time">Hora</label>
    <input id="t-time" type="time" class="form-control" value="12:30">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-file">Arquivo</label>
    <input id="t-file" type="file" class="form-control">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-color">Cor</label>
    <input id="t-color" type="color" class="form-control form-control-color" value="#3366cc">
  </div>
  <div class="col-md-4">
    <label class="form-label" for="t-ro">Somente leitura</label>
    <input id="t-ro" class="form-control" value="readonly" readonly>
  </div>
  <div class="col-md-4">

    <input id="t-dis" class="form-control" value="disabled" disabled>
  </div>
</div>
    Limitação

    Os popups nativos de data, hora e cor continuam do navegador; o CSS só estiliza o campo.

    Texto de ajuda e extras#

    form-text: mínimo de 8 caracteres.
    HTML
    <div style="max-width:360px">
  <label class="form-label" for="vg-s">Senha</label>
  <input class="form-control" id="vg-s" type="password" aria-describedby="vg-help">
  <div id="vg-help" class="form-text">form-text: mínimo de 8 caracteres.</div>
  <div class="form-check form-check-reverse mt-2">
    <input class="form-check-input" type="checkbox" id="vg-rev">
    <label class="form-check-label" for="vg-rev">form-check-reverse</label>
  </div>
</div>
