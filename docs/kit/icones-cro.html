    Ícone clicável#

    HTML
    <button class="cro-ico cro-ico--page-first" aria-label="primeira página"></button>
<button class="cro-ico cro-ico--page-next" aria-label="próxima página"></button>
<span class="cro-icon-view" title="visão"></span>
<span class="cro-icon-view is-on" title="visão ligada"></span>
    Atenção

    Ícones clicáveis precisam de aria-label. Para ícones de terceiros, veja Ícones.

    Setas, alça e visão#

    HTML
    <span class="cro-arrow cro-arrow--up" title="up"></span>
<span class="cro-arrow cro-arrow--down" title="down"></span>
<span class="cro-arrow cro-arrow--left" title="left"></span>
<span class="cro-arrow cro-arrow--right" title="right"></span>
<span class="cro-arrow cro-arrow--prev" title="prev"></span>
<span class="cro-arrow cro-arrow--next" title="next"></span>
<span class="cro-grip" title="alça de redimensionar"></span>
<span class="cro-dialog-handle" title="alça da barra de diálogo"></span>
    Classe Papel
    cro-arrow--up/down/left/right Setas de quest (10×10)
    cro-arrow--prev/next Setas de paginação (11×11)
    cro-grip Alça de redimensionar janela (13×13)
    cro-dialog-handle Alça vertical da barra de diálogo
    cro-icon-view (+ is-on) Alternador "visão ligada/desligada"
