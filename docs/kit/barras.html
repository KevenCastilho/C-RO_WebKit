    Peças nativas do kit

    Barras, progress e grp

    Nativo do kit

    Barras de HP/SP/experiência, ícones de grupo e barras de botões.

    Progress (cro-progress)#

    Defina o preenchimento com a variável --p (0–100).

    HTML
    <div style="max-width:260px">
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar" style="--p:70"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--orange" style="--p:60"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--red" style="--p:20"></div>
  </div>
  <div class="cro-progress">
    <div class="cro-progress__bar cro-progress__bar--blue" style="--p:90"></div>
  </div>
</div>

    Cores: --green, --blue, --cyan, --yellow, --orange, --red, --pink, --purple, --gray e --sp.

    Barra de experiência (cro-exp)#

    HTML
    <div class="cro-exp" style="--p:62;width:260px"></div>

    Atualizar por JavaScript#

    HTML
    <div class="cro-progress" style="width:260px">
  <div class="cro-progress__bar" id="hpbar" style="--p:100"></div>
</div>
<p class="mt-2"><button class="btn btn-secondary btn-sm" id="hpdown">Levar dano</button></p>
    JS
    var hp = 100;
document.getElementById('hpdown').addEventListener('click', function () {
  hp = hp <= 15 ? 100 : hp - 15;
  CRO.bar(document.getElementById('hpbar'), hp);   // abaixo de 25% a barra fica vermelha
});

    Grp (status de grupo)#

    HTML
    <span class="cro-grp cro-grp--offline" title="offline"></span>
<span class="cro-grp cro-grp--online" title="online"></span>
<span class="cro-grp cro-grp--leader" title="líder"></span>

    Barra de botões#

    HTML
    <div class="cro-btnbar" style="width:260px">
  <button class="cro-mesbtn" style="width:80px">Um</button>
  <button class="cro-mesbtn" style="width:80px">Dois</button>
</div>
    Nota

    Com Bootstrap, .progress / .progress-bar fazem o mesmo (Progress).

    Variações completas#

    Barras cro-progress__bar--*: green, blue, cyan, yellow, orange, red, pink, purple, gray, sp.

    HTML
    <div style="max-width:260px">
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--green" style="--p:80"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--cyan" style="--p:70"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--yellow" style="--p:60"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--pink" style="--p:50"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--purple" style="--p:40"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--gray" style="--p:30"></div>
  </div>
  <div class="cro-progress">
    <div class="cro-progress__bar cro-progress__bar--sp" style="--p:75"></div>
  </div>
</div>

    cro-progress--fluid faz a barra ocupar 100% da largura do contêiner:

    HTML
    <div class="cro-progress cro-progress--fluid">
  <div class="cro-progress__bar" style="--p:55"></div>
</div>

    Barras de botões (cro-btnbar) e de skills (cro-skillbar)#

    HTML
    <div class="cro-btnbar" style="width:260px;margin-bottom:6px">
  <button class="cro-mesbtn" style="width:80px">Normal</button>
</div>
<div class="cro-btnbar cro-btnbar--tall" style="width:260px;margin-bottom:6px">
  <button class="cro-mesbtn" style="width:80px">tall</button>
</div>
<div class="cro-btnbar cro-btnbar--xl" style="width:260px;margin-bottom:6px">
  <button class="cro-mesbtn" style="width:80px">xl</button>
</div>
<div class="cro-skillbar" style="width:260px;margin-bottom:6px"></div>
<div class="cro-skillbar cro-skillbar--bottom" style="width:260px"></div>
    Classe Papel
    cro-btnbar (--tall, --xl) Faixa listrada de barra de botões (21px; --tall 29px)
    cro-skillbar Cabeçalho (20px) da janela de skills
    cro-skillbar--bottom Rodapé (32px) da janela de skills
