    Peças nativas do kit

    Árvore, menu e lista

    Nativo do kit

    Árvore de pastas (details), menu de contexto, lista selecionável e tabela.

    Árvore#

    • Equipamentos
      • Espada
      • Escudo
      • Armaduras
        • Couro
    • Consumíveis
      • Poção
    HTML
    <ul class="cro-tree" role="tree" style="max-width:260px">
  <li>
    <details open>
      <summary>Equipamentos</summary>
      <ul>
        <li>Espada</li>
        <li>Escudo</li>
        <li>
          <details>
            <summary>Armaduras</summary>
            <ul>
              <li>Couro</li>
            </ul>
          </details>
        </li>
      </ul>
    </details>
  </li>
  <li>
    <details>
      <summary>Consumíveis</summary>
      <ul>
        <li>Poção</li>
      </ul>
    </details>
  </li>
</ul>

    Menu#

    • Abrir
    • Renomear
    • Desabilitado
    HTML
    <ul class="cro-menu" style="width:160px">
  <li>Abrir</li>
  <li>Renomear</li>
  <li role="separator"></li>
  <li aria-disabled="true">Desabilitado</li>
</ul>

    Lista e tabela#

    • Item A
    • Selecionado
    • Item C
    NomeLv
    Ana99
    Bia50
    HTML
    <ul class="cro-list" style="width:180px">
  <li class="cro-list__item">Item A</li>
  <li class="cro-list__item is-selected">Selecionado</li>
  <li class="cro-list__item">Item C</li>
</ul>
<table class="cro-table" style="width:240px">
  <thead>
    <tr>
      <th>Nome</th>
      <th>Lv</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ana</td>
      <td>99</td>
    </tr>
    <tr>
      <td>Bia</td>
      <td>50</td>
    </tr>
  </tbody>
</table>

    Paginação#

    HTML
    <div class="cro-pager">
  <button class="cro-ico cro-ico--page-first" aria-label="primeira"></button>
  <button class="cro-ico cro-ico--page-prev" aria-label="anterior"></button>
  <button class="cro-pager__n">1</button>
  <button class="cro-pager__n is-current">2</button>
  <button class="cro-pager__n">3</button>
  <button class="cro-ico cro-ico--page-next" aria-label="próxima"></button>
  <button class="cro-ico cro-ico--page-last" aria-label="última"></button>
</div>
    Nota

    A seleção azul vem de --cro-sel-bg. Com Bootstrap: List group, Dropdowns, Accordion.

    Estados por classe#

    Itens de menu desabilitados: aria-disabled="true" ou a classe is-disabled. Itens de lista selecionados: is-selected. Páginas atuais do pager: is-current.

    • Normal
    • is-disabled
    • aria-disabled
    HTML
    <ul class="cro-menu" style="width:160px">
  <li>Normal</li>
  <li class="is-disabled">is-disabled</li>
  <li aria-disabled="true">aria-disabled</li>
</ul>
