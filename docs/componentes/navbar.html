    Navbar

    Drop-in Bootstrap

    Barras de navegação. Os nav-link e o toggler são botões do kit; marca e collapse seguem o Bootstrap.

    C-RO
    • Início
    • Itens
    • Desabilitado
    HTML
    <nav class="navbar navbar-expand-md">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">C-RO</a>
    <button
      class="navbar-toggler"
      type="button"
      data-bs-toggle="collapse"
      data-bs-target="#nvEx"
      aria-controls="nvEx"
      aria-expanded="false"
      aria-label="Alternar navegação">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="nvEx">
      <ul class="navbar-nav me-auto">
        <li class="nav-item">
          <a class="nav-link active" aria-current="page" href="#">Início</a>
        </li>
        <li class="nav-item"><a class="nav-link" href="#">Itens</a></li>
        <li class="nav-item">
          <a class="nav-link disabled" aria-disabled="true">Desabilitado</a>
        </li>
      </ul>
      <form class="d-flex" role="search">
        <input
          class="form-control form-control-sm me-2"
          type="search"
          placeholder="Buscar"
          aria-label="Buscar">
        <button class="btn btn-primary btn-sm" type="submit">Ir</button>
      </form>
    </div>
  </div>
</nav>

    Com dropdown#

    Menu
    • Conta
      • Perfil
      • Sair
    HTML
    <nav class="navbar navbar-expand">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Menu</a>
    <ul class="navbar-nav">
      <li class="nav-item dropdown">
        <a
          class="nav-link dropdown-toggle"
          href="#"
          data-bs-toggle="dropdown"
          aria-expanded="false">
          Conta
        </a>
        <ul class="dropdown-menu">
          <li><a class="dropdown-item" href="#">Perfil</a></li>
          <li><a class="dropdown-item" href="#">Sair</a></li>
        </ul>
      </li>
    </ul>
  </div>
</nav>
    Nota

    Esta própria documentação usa uma navbar do kit no topo da página.

    Variações#

    navbar-darknavbar-text
    HTML
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark mb-2">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">navbar-dark</a>
    <span class="navbar-text">navbar-text</span>
  </div>
</nav>
    • Expansão responsiva: navbar-expand-sm, -md, -lg, -xl, -xxl (ou navbar-expand sempre expandida).
    • Texto: navbar-text para texto sem link.
    • Rolagem: navbar-nav-scroll limita a altura do menu aberto.
    • Escura: navbar-dark (com bg-dark) usa a superfície escura do Bootstrap.

    Expansão: navbar-expand-sm|md|lg|xl|xxl. Offcanvas responsivo: offcanvas-sm|md|lg|xl|xxl.
