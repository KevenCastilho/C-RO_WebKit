    Componentes

    Card

    Drop-in Bootstrap

    Um card é uma janela completa do jogo: barra de título (card-header), corpo, rodapé. As partes só aparecem quando você as declara.

    Exemplo#

    Status
    Poring

    Nível 1, HP 50.

    Atacar
    HTML
    <div class="card" style="max-width:300px">
  <div class="card-header">Status</div>
  <div class="card-body">
    <h5 class="card-title">Poring</h5>
    <p class="card-text">Nível 1, HP 50.</p>
  </div>
  <div class="card-footer"><a href="#" class="btn btn-primary btn-sm">Atacar</a></div>
</div>

    Só corpo (sem header)#

    Um card simples, só com corpo.
    HTML
    <div class="card" style="max-width:300px">
  <div class="card-body">Um card simples, só com corpo.</div>
</div>

    Listas e imagens#

    Inventário
    • Poção Vermelha
    • Asa de Mosca
    • Maçã
    HTML
    <div class="card" style="max-width:300px">
  <div class="card-header">Inventário</div>
  <ul class="list-group list-group-flush">
    <li class="list-group-item">Poção Vermelha</li>
    <li class="list-group-item">Asa de Mosca</li>
    <li class="list-group-item">Maçã</li>
  </ul>
</div>

    Grade de cards#

    A
    Texto
    B
    Texto maior para ver a altura igual.
    C
    Texto
    HTML
    <div class="row row-cols-1 row-cols-md-3 g-2">
  <div class="col">
    <div class="card h-100">
      <div class="card-header">A</div>
      <div class="card-body">Texto</div>
    </div>
  </div>
  <div class="col">
    <div class="card h-100">
      <div class="card-header">B</div>
      <div class="card-body">Texto maior para ver a altura igual.</div>
    </div>
  </div>
  <div class="col">
    <div class="card h-100">
      <div class="card-header">C</div>
      <div class="card-body">Texto</div>
    </div>
  </div>
</div>
    Nota

    A versão nativa é cro-window — veja Janela e titlebar.

    <div class="card-body">
      <h6 class="card-subtitle mb-1">card-subtitle</h6>

    Imagens em cards: card-img-top, card-img-bottom, card-img e, com texto sobre a imagem, card-img-overlay:

    card-img-overlay

    Texto sobre a imagem.

    HTML
    <div class="card text-bg-dark" style="max-width:300px">
  <img
    src="https://placehold.co/300x120"
    class="card-img"
    width="300"
    height="120"
    alt="imagem">
  <div class="card-img-overlay">
    <h5 class="card-title">card-img-overlay</h5>
    <p class="card-text">Texto sobre a imagem.</p>
  </div>
</div>
