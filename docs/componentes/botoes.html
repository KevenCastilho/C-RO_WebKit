    Componentes

    Botões

    Drop-in Bootstrap

    O botão de 20px do jogo (degradê azul de 1px por linha, borda cinza) com as cores contextuais do Bootstrap derivadas.

    Cores#

    HTML
    <button class="btn btn-secondary">Secondary</button>
<button class="btn btn-primary">Primary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-danger">Danger</button>
<button class="btn btn-warning">Warning</button>
<button class="btn btn-info">Info</button>
<button class="btn btn-light">Light</button>
<button class="btn btn-dark">Dark</button>
<button class="btn btn-link">Link</button>
    Derivado/inventado

    O jogo só tem o botão azul-acinzentado padrão (CONFIRMADO). As cores contextuais são derivadas dele (DERIVADO).

    Contorno#

    HTML
    <button class="btn btn-outline-primary">Primary</button>
<button class="btn btn-outline-success">Success</button>
<button class="btn btn-outline-danger">Danger</button>
<button class="btn btn-outline-secondary">Secondary</button>

    Tamanhos#

    HTML
    <button class="btn btn-primary btn-lg">Grande</button>
<button class="btn btn-primary">Padrão</button>
<button class="btn btn-primary btn-sm">Pequeno</button>

    Os tamanhos usam a altura flexível do sprite: o degradê é redesenhado sem esticar a borda.

    Estados#

    Link desabilitado
    HTML
    <button class="btn btn-primary active">Ativo</button>
<button class="btn btn-primary" disabled>Desabilitado</button>
<a class="btn btn-primary disabled" role="button" aria-disabled="true">Link desabilitado</a>

    Elementos#

    a
    HTML
    <button class="btn btn-primary" type="button">button</button>
<a class="btn btn-primary" href="#" role="button">a</a>
<input class="btn btn-primary" type="submit" value="input">

    Bloco e alternância#

    HTML
    <div class="d-grid gap-2" style="max-width:260px">
  <button class="btn btn-primary">Bloco</button>
  <button class="btn btn-secondary">Bloco</button>
</div>
<button class="btn btn-primary mt-2" data-bs-toggle="button">
  Alternar (data-bs-toggle="button")
</button>

    Botões nativos do kit#

    Veja Botões cro-*: cro-btn, cro-mesbtn, cro-sys-btn, cro-dialbtn.
