    C-RO

    Kit de UI no estilo Classic Ragnarok Online (2002) feito só de CSS, com o Bootstrap 5.3.8 tematizado — entregue em um CSS e um JS. Use a marcação normal do Bootstrap e o resultado sai com a cara do jogo.

    Comece em 1 minuto#

    Inclua o CSS no <head> e o JS antes do </body>. Só isso. Nenhuma classe nova é necessária: btn, card, modal, form-control... já saem no visual do jogo.

    HTML
    <!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Meu site</title>
  <link rel="stylesheet" href="c-ro-bs.min.css">
</head>
<body>
  <button class="btn btn-primary">Olá, aventureiro!</button>
  <script src="c-ro-bs.min.js"></script>
</body>
</html>

    Resultado:

    Atenção
    HTML
    <button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-danger">Danger</button>
<span class="badge text-bg-warning">Atenção</span>

    O que vem de graça#

    • Visual do jogo em todos os componentes do Bootstrap, sem mudar sua marcação.
    • Cursores do Ragnarok (seta, mão, relógio, espada, porta...) aplicados automaticamente em toda a página, inclusive animados. Veja Cursores.
    • Favicon automático quando o site não declara um. Veja Favicon.
    • Peças nativas cro-* para o que o Bootstrap não tem: janela com barra de título, slots de inventário, árvore, menus e diálogos CRO.alert/confirm/prompt/menu.
    • O kit sempre vence: o Bootstrap fica em @layer bootstrap, o kit fora dele. Se você escrever seu próprio CSS, o seu vence o do kit.
    Nota

    Esta documentação é feita com o próprio C-RO. Tudo o que você vê aqui (navbar, cards, tabelas, formulários) é o kit em ação.
