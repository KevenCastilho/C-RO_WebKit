Overflow

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.

utilitarios/overflow.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Controle de transbordamento.

<div class="overflow-auto border p-2" style="width:160px;height:60px">
  Conteúdo longo que rola dentro da caixa porque tem overflow-auto. Mais texto aqui para rolar.
</div>
<div class="overflow-hidden border p-2" style="width:160px;height:60px">
  Conteúdo cortado com overflow-hidden, não rola.
</div>
Note

Barras de rolagem no visual do jogo valem em Chromium/Safari; use a classe cro-native-scroll para manter a nativa em um elemento.

Todas as classes

overflow-auto, -hidden, -visible, -scroll e por eixo: overflow-x-auto|hidden|visible|scroll, overflow-y-auto|hidden|visible|scroll.
