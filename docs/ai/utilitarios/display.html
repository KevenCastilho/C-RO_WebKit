Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Mostra, esconde e alterna o tipo de display.

<div class="d-inline p-2 border">d-inline</div>
<div class="d-block p-2 border">d-block</div>
<div class="d-none d-md-block p-2 border">visível de md para cima</div>
<div class="d-flex p-2 border">d-flex</div>

Impressão

d-print-none e d-print-block controlam o que aparece ao imprimir.

Todos os valores

d-none, d-inline, d-inline-block, d-block, d-grid, d-inline-grid, d-table, d-table-row, d-table-cell, d-flex, d-inline-flex. Com breakpoints: d-md-none. Impressão: d-print-none, -block, -inline, -inline-block, -flex, -inline-flex, -grid, -inline-grid, -table, -table-row, -table-cell.
