Utilitários são classes de uma propriedade só. Todos os do Bootstrap 5.3 funcionam, fora do layer; só display e visibilidade levam !important.

Como funcionam

<div class="p-3 border rounded bg-light">p-3 border rounded bg-light</div>
<div class="p-2 text-bg-primary fw-bold">text-bg-primary fw-bold</div>
  • Aplicam-se sem quebrar o kit: o CSS do kit está fora do layer do Bootstrap, e os utilitários vêm depois.
  • Para display (d-none, d-flex) e visibilidade o Bootstrap usa !important, e o kit mantém assim para que d-none esconda de verdade.
  • São responsivos: d-md-flex, mb-lg-3, text-xl-end.

Famílias

Fundo · Bordas · Cores · Display · Flex · Float · Interações · Link · Object fit · Opacidade · Overflow · Posição · Sombras · Tamanho · Espaçamento · Texto · Alinhamento vertical · Visibilidade

Note

Utilitários próprios do kit: cro-flex, cro-gap-2, cro-items-center, cro-m-0, cro-mb-2, cro-mb-4, cro-mt-2, cro-block. Servem para quem usa só c-ro.css, sem Bootstrap.
