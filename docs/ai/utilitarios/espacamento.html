Espaçamento

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.

utilitarios/espacamento.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Margem e padding de 0 a 5, por lado e por breakpoint.

<div class="bg-white p-0 border">p-0</div>
<div class="bg-white p-1 border">p-1</div>
<div class="bg-white p-2 border">p-2</div>
<div class="bg-white p-3 border">p-3</div>
<div class="bg-white p-4 border">p-4</div>
<div class="bg-white p-5 border">p-5</div>

Formato: {propriedade}{lado}-{breakpoint}-{tamanho} — ex.: mt-3, px-md-4, ms-auto, gap-2.

Propriedade Lados
m margem, p padding t b s e x y (vazio = todos)

Gap

gap-0 … gap-5, row-gap-* e column-gap-* (em contêineres d-flex ou d-grid).
