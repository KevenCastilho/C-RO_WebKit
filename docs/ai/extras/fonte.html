O kit usa a Nimbus Sans (clone livre da Helvetica) em todo texto. Esta página mostra, ao vivo, se ela carregou no seu navegador.

Como é aplicada

--cro-font-ui, --cro-font-title e --cro-font-btn valem "C-RO Helvetica", sans-serif. "C-RO Helvetica" é um nome do kit, declarado em @font-face (Regular e Bold) apontando para fonts/NimbusSans-*.woff2; o itálico é sintetizado pelo navegador. A pasta fonts/ precisa ficar ao lado do CSS (dist/fonts/ neste site).

Note

Para usar a Helvetica real (fonte comercial, não incluída aqui), declare-a no seu CSS com @font-face e aponte --cro-font-ui para ela. Para comparar, use a linha de teste abaixo: ela mostra a mesma frase na fonte do kit e na fonte genérica sans-serif do seu sistema (R, G, a, 1 e & são os melhores sinais).

Verificação ao vivo

<p style="font:36px/1.2 'C-RO Helvetica', monospace">
  Fonte do kit: Rag Gy 1 Qej
  &amp;
  <b>Bold</b>
  <i>Oblique</i>
</p>
<p style="font:36px/1.2 sans-serif">sans-serif do sistema: Rag Gy 1 Qej&amp;</p>
<pre id="fonte-diag" style="white-space:pre-wrap">verificando…</pre>
(function () {
  var out = document.getElementById('fonte-diag');
  var faces = ['400 12px', '700 12px'];
  Promise.all(faces.map(function (f) { return document.fonts.load(f + ' "C-RO Helvetica"'); })).then(function () {
    var linhas = faces.map(function (f) { return f + ' → ' + (document.fonts.check(f + ' "C-RO Helvetica"') ? 'carregada' : 'NÃO carregou'); });
    var carregadas = Array.from(document.fonts).filter(function (x) { return x.family.indexOf('C-RO Helvetica') >= 0; })
      .map(function (x) { return x.weight + ' ' + x.style + ': ' + x.status; });
    out.textContent = linhas.join('\n') + '\n\nFontFace: ' + carregadas.join(' | ') + '\nCorpo da página (font-family): ' + getComputedStyle(document.body).fontFamily;
  });
})();

Se alguma linha disser NÃO carregou, a pasta fonts/ não está sendo encontrada ao lado do CSS: abra o DevTools → aba Network → filtro Font e veja o erro de NimbusSans-Regular.woff2.
