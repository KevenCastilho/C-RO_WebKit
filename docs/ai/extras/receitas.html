Página completa: login, abas, confirmação e barra de HP (peças nativas)

A tela mais comum de um teste, pronta e fiel ao jogo. Um só tipo de botão (cro-btn), janelas de largura fixa, rodapé como irmão do corpo, CRO.confirm com await. Salve como index.html ao lado de c-ro-bs.min.css, c-ro-bs.min.js e da pasta fonts/ (ou troque os dois endereços pelos de https://kevencastilho.github.io/C-RO_WebKit/dist/).

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>C-RO: login, abas, confirmação e HP</title>
    <link rel="stylesheet" href="c-ro-bs.min.css">
  </head>
  <body>
    <div style="display:flex; gap:24px; flex-wrap:wrap; padding:24px; align-items:flex-start">
      <!-- Login: o rodapé é IRMÃO do corpo, não vai dentro dele -->
      <section class="cro-window" style="width:300px">
        <header class="cro-titlebar"><span class="cro-titlebar__title">Login</span></header>
        <div class="cro-window__body">
          <div class="cro-field">
            <label class="cro-label" for="usuario">Usuário</label>
            <input class="cro-input" id="usuario">
          </div>
          <div class="cro-field">
            <label class="cro-label" for="senha">Senha</label>
            <input class="cro-input" id="senha" type="password">
          </div>
        </div>
        <footer class="cro-window__footer">
          <button class="cro-btn" id="entrar">Entrar</button>
        </footer>
      </section>
      <!-- Personagem: abas nativas + barra de HP -->
      <section class="cro-window" style="width:340px">
        <header class="cro-titlebar">
          <span class="cro-titlebar__title">Personagem</span>
        </header>
        <div class="cro-window__body">
          <div data-cro-tabs data-cro-panels="#paineis">
            <div class="cro-tabs">
              <button class="cro-tabs__btn is-active" data-cro-tab="status">Status</button>
              <button class="cro-tabs__btn" data-cro-tab="equip">Equipamento</button>
            </div>
          </div>
          <div class="cro-tab-panels" id="paineis">
            <div class="cro-tab-panel" data-cro-panel="status">
              <p>HP 600 / 1000</p>
              <div class="cro-progress">
                <div class="cro-progress__bar" style="--p:60"></div>
              </div>
              <p><button class="cro-btn" id="sair">Sair da guilda?</button></p>
              <div class="cro-box">
                <div class="cro-box__frame" id="resultado">Nenhuma escolha feita.</div>
              </div>
            </div>
            <div class="cro-tab-panel" data-cro-panel="equip" hidden>
              <p>Nenhum equipamento.</p>
            </div>
          </div>
        </div>
      </section>
    </div>
    <script src="c-ro-bs.min.js"></script>
    <script>
    document.getElementById('entrar').addEventListener('click', async () => {
      await CRO.alert('Bem-vindo, ' + (document.getElementById('usuario').value || 'aventureiro') + '!');
    });
    document.getElementById('sair').addEventListener('click', async () => {
      const sim = await CRO.confirm('Você realmente quer sair da guilda?', { ok: 'Sim', cancel: 'Não' });
      document.getElementById('resultado').textContent = sim ? 'Você escolheu: SIM' : 'Você escolheu: NÃO';
    });
  </script>
  </body>
</html>

Confirmação com async/await

document.querySelector('#excluir').addEventListener('click', async () => {
  if (await CRO.confirm('Excluir o personagem?', { ok: 'Excluir', cancel: 'Cancelar' })) {
    await CRO.alert('Personagem excluído.');
  }
});
