Os atributos HTML que controlam comportamento do kit, sem JavaScript seu.

Atributo Onde Faz
data-cro-tabs contêiner dos botões de aba Liga as abas ARIA do kit
data-cro-panels="#seletor" junto de data-cro-tabs Indica onde estão os painéis
data-cro-tab="id" botão da aba Aponta o painel
data-cro-panel="id" painel Identifica o painel
data-cro-select <select> Popup de opções no visual do jogo
data-cro-color .cro-progress__bar Impede que CRO.bar() troque a cor para vermelho
data-cro-top link Cursor "seta para cima"
data-cro-handwriting qualquer elemento Cursor de caneta
data-cro-cursor-anim="off" <html> Desliga a animação do cursor
data-cro-favicon="off" <html> Desliga o favicon automático
data-cro-pen <html> Marcado pelo kit quando o ponteiro é uma caneta (não escreva)
data-cro-favicon-link <link> Marcado pelo kit nos links que ele injeta (não escreva)

Exemplos

<div data-cro-tabs data-cro-panels="#p">
  <div class="cro-tabs"><button class="cro-tabs__btn is-active" data-cro-tab="1">A</button></div>
</div>
<div class="cro-tab-panels" id="p"><div data-cro-panel="1">Painel A</div></div>

<select data-cro-select>…</select>
<div class="cro-progress"><div class="cro-progress__bar" data-cro-color style="--p:10"></div></div>

Estes atributos têm tudo a ver com o JS do kit; veja JavaScript.
