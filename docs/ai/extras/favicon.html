Favicon automático

Type
Kit extra. A feature Bootstrap does not have.
Section
Extras do kit
Human version (rendered examples)
extras/favicon.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.
data-cro-* attributes in this page
data-cro-favicon data-cro-favicon-link

Se o site não declara favicon, o kit aplica o dele — um retrato em pixel art — sem você fazer nada.

A regra

  1. Ao carregar, o JS procura um <link rel="icon"> (ou shortcut icon) com href preenchido no <head>.
  2. Não achou: injeta o favicon do kit (PNG 32px) e, se também não houver, um apple-touch-icon de 180px.
  3. Achou: não faz nada. O favicon do site sempre vence.
  4. Depois: se o site adicionar um favicon, o do kit é removido; se remover o dele, o do kit volta.
<!-- sem <link rel="icon">: aparece o favicon do C-RO -->
<head><meta charset="utf-8"><title>Meu site</title></head>

<!-- com <link rel="icon">: aparece o seu -->
<head><link rel="icon" href="/meu.ico"></head>

Desligar

<html data-cro-favicon="off">

Teste ao vivo

Esta página não declara favicon: o ícone da aba é o do kit. Os links injetados:

<ul id="fv-list" class="mb-0"></ul>
var ul = document.getElementById('fv-list');
document.querySelectorAll('link[rel~=icon],link[rel=apple-touch-icon]').forEach(function (l) {
  var li = document.createElement('li');
  li.textContent = l.getAttribute('rel') + ' ' + (l.getAttribute('sizes') || '') + ' — ' +
    (l.hasAttribute('data-cro-favicon-link') ? 'injetado pelo kit' : 'do site');
  ul.appendChild(li);
});

Arquivos

Em dist/favicon/: favicon.svg, favicon-32.png, apple-touch-icon.png e favicon.ico (16/32/48) — úteis se você quiser servir o ícone como arquivo.

Limitation

Um /favicon.ico na raiz do site sem <link> não é detectável sem uma requisição. Nesse caso o do kit vale; declare o seu <link rel="icon"> para vencer.

Note

A arte (30×30) foi fornecida pelo autor do projeto. O SVG não vai embutido no bundle (pesaria ~56 KB).
