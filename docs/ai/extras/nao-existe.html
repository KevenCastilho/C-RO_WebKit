Lista direta do que o C-RO não oferece, com a alternativa. Se algo não está documentado aqui nem no índice de classes, não existe: não invente classes.

Resposta curta

Pergunta Resposta O que fazer
Existe janela de chat pronta? Não. Existe só a barra de entrada do chat (cro-dialog-bar: nome, campo de texto e alça), mais o ícone cro-ico--chatmode. Não há área de mensagens, rolagem de log nem abas de chat. Monte com cro-window + a barra cro-dialog-bar. Veja Sysbox e dica.
Existe modo escuro? Não. Não há alternativa; o visual segue o jogo de 2002.
Existe suporte a RTL (dir="rtl")? Não. Não suportado.
Existe janela pronta de inventário, equipamento, status, habilidades, grupo ou minimapa? Não. Existem as peças: cro-window, cro-slot, cro-progress, cro-tabs, cro-tree, cro-list. Componha as janelas com as peças. Veja Janela e Slots.
Existe backend de login, sessão ou jogo? Não. É só CSS e JS de interface. O formulário de login é visual; ligue ao seu servidor.
O kit usa Node, React, Vue ou etapa de build para usar? Não. Para usar bastam um CSS e um JS. <link> e <script>.
Os botões/barras/abas seguem as variáveis de cor? Não. São imagens (sprites) desenhadas em CSS. Só textos, campos, fundos e bordas seguem tokens --cro-*. Veja Tokens e Customização.
As cores do tema do Bootstrap (primary, secondary...) mudam em tempo de execução? Não. Estão compiladas no CSS. —
Os pickers nativos (data, hora, cor) e datalist seguem o visual do jogo? Não. Ficam nativos. Veja Navegadores e limites.

Como ter certeza de que uma classe existe

Procure a classe no índice de classes cro-*. Se não estiver lá, ela não existe. O mesmo vale para atributos: a lista completa está em Atributos data-cro-* e os tokens em Tokens.

Warning

Ausência de resultado numa busca de texto não prova que algo não existe, e presença de um nome plausível (cro-chat, cro-hp-bar) não prova que existe. A fonte de verdade é o índice de classes.
