Como o kit escolhe o cursor sem você fazer nada — mesma lógica dos cursores nativos do Windows.

Tabela de gatilhos

Situação Cursor Gatilho no HTML
Padrão Seta animada qualquer lugar
Link Mão apontando a[href], area[href]
Dica / ajuda Mão com ? [title], abbr[title], [data-bs-toggle=tooltip], [data-bs-toggle=popover], .tooltip, .popover
Aviso / erro Mão com ! .alert, [role=alert], .invalid-feedback, .is-invalid, [aria-invalid=true]
Ocupado (região) Seta + Poring [aria-busy=true]
Ocupado (página) Poring html[aria-busy=true]
Arrastar Mão aberta / fechada [draggable=true] (e :active)
Texto Barra I campos editáveis: input de texto, textarea, [contenteditable]
Caneta Caneta canvas, [data-cro-handwriting]; e campos editáveis quando o ponteiro é uma caneta
Voltar ao topo Seta para cima [data-cro-top]
Desabilitado Proibido (⊘) :disabled, [aria-disabled=true]
Redimensionar, mover, esperar... Cursor do jogo cursor nativo (ns-resize, move, wait...) convertido

Prioridade

Entre regras do kit, a última vence: ajuda < aviso < ocupado < arrastar < link < topo < texto < caneta < desabilitado. Casos práticos:

  • Um link com title mostra a mão do link (o link vence a "?").
  • Um campo de texto com title mostra a barra I.
  • Um campo inválido continua com a barra I (a mão "!" não vence campos editáveis).
  • Um botão disabled com title mostra o cursor proibido.

Experimente

<div class="d-flex flex-wrap gap-2 align-items-center">
  <a href="#">link (mão)</a>
  <span title="com title: mão com ?">dica (?)</span>
  <abbr title="Ragnarok Online">RO</abbr>
  <div class="alert alert-warning mb-0 py-1">alerta (mão com !)</div>
  <input class="form-control" style="width:140px" value="campo (barra I)">
  <button class="btn btn-secondary" disabled>desabilitado</button>
  <div draggable="true" class="bd-demo-box">arraste (mão)</div>
  <a href="#" data-cro-top>voltar ao topo (↑)</a>
  <div aria-busy="true" class="bd-demo-box">aria-busy</div>
</div>

Controle fino

<html data-cro-cursor-anim="off">           <!-- sem animação -->
<canvas data-cro-handwriting></canvas>      <!-- cursor de caneta -->
<a href="#topo" data-cro-top>Topo</a>       <!-- seta para cima -->
<main aria-busy="true">carregando...</main> <!-- seta + Poring -->

Para tirar o cursor do kit de um elemento, declare o seu: .x { cursor: auto; } (palavra-chave: usa o cursor nativo).
