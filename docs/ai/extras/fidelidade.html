Fidelidade: confirmado e derivado

O kit nunca finge. Cada item é marcado como vindo do jogo, deduzido ou inventado.

Os rótulos

Rótulo Significa
CONFIRMADO Medido diretamente nos bitmaps/sprites do jogo (cores, tamanhos, pixels).
DERIVADO Deduzido de forma documentada de elementos reais (ex.: cores contextuais dos botões; seleção em listas).
INVENTADO Não existe no jogo; criado no estilo dele (ex.: barra I do cursor, copy/alias/zoom, favicon em tamanhos novos).
NÃO DETERMINADO Não virou token "bonito": fica documentado como lacuna.

Onde o jogo não tem equivalente

Para breadcrumb, carousel, spinner, placeholder, offcanvas, popover (seta), toast colorido, dropdown com cabeçalho, listras e animação do progress etc., o visual é derivado e marcado nas páginas com o aviso Derivado/inventado.

Note

A regra do projeto: "o kit sempre vence o Bootstrap; onde o jogo não define, vale o Bootstrap e o item é marcado como derivado".

Placeholder de "não determinado"

A classe cro-undefined marca visualmente um elemento cujo visual clássico não foi determinado (borda tracejada cinza), em vez de inventar uma aparência bonita:

<div class="cro-undefined" style="max-width:260px">Elemento sem referência no jogo</div>
