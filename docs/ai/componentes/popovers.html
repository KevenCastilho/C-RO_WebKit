Warning

Popovers precisam ser inicializados: new bootstrap.Popover(el) (a documentação já faz isso nos exemplos). Veja JavaScript.

Derived/invented (not in the original game)

A seta do popover é a do Bootstrap (o jogo não tem balão com seta). Elementos com popover ganham o cursor "mão com ?" automaticamente.

Marcação gerada

O Bootstrap gera .popover com as classes de posição bs-popover-top|bottom|start|end|auto. Personalize com data-bs-custom-class="minha-classe".

Partes do popover gerado: popover-arrow, popover-header (título) e popover-body (conteúdo).
