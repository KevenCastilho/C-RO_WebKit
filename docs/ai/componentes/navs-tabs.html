Navs e abas

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.

nav-tabs e nav-pills viram as abas do jogo: horizontais em pílula e, com flex-column, verticais em escada.

Outras variações

<ul class="nav nav-underline mb-2">
  <li class="nav-item"><a class="nav-link active" href="#">nav-underline</a></li>
  <li class="nav-item"><a class="nav-link" href="#">B</a></li>
</ul>
<ul class="nav nav-tabs nav-fill mb-2">
  <li class="nav-item"><a class="nav-link active" href="#">nav-fill</a></li>
  <li class="nav-item"><a class="nav-link" href="#">B</a></li>
</ul>
<ul class="nav nav-pills nav-justified">
  <li class="nav-item"><a class="nav-link active" href="#">nav-justified</a></li>
  <li class="nav-item"><a class="nav-link" href="#">B</a></li>
</ul>
  • nav-fill: cada item ocupa o espaço proporcional ao conteúdo. nav-justified: todos com largura igual.
  • nav-underline: derivação do Bootstrap (sublinhado no ativo).
  • Em cards: card-header-tabs e card-header-pills (veja Card).
