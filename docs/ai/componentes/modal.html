Modal

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Componentes
Human version (rendered examples)
componentes/modal.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Janelas modais. O modal é uma janela do jogo: modal-header vira a barra de título e btn-close o botão fechar.

Exemplo

<button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#modalEx">
  Abrir modal
</button>
<div
  class="modal fade"
  id="modalEx"
  tabindex="-1"
  aria-labelledby="modalExLabel"
  aria-hidden="true">
  <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content">
      <div class="modal-header">
        <h1 class="modal-title fs-5" id="modalExLabel">Confirmar</h1>
        <button
          type="button"
          class="btn-close"
          data-bs-dismiss="modal"
          aria-label="Fechar"></button>
      </div>
      <div class="modal-body">Deseja mesmo sair do jogo?</div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">
          Cancelar
        </button>
        <button type="button" class="btn btn-primary">Sair</button>
      </div>
    </div>
  </div>
</div>

Tamanhos e rolagem

<div class="modal-dialog modal-sm">…</div>
<div class="modal-dialog modal-lg modal-dialog-scrollable">…</div>
<div class="modal-dialog modal-fullscreen">…</div>

Controle por JavaScript

<button class="btn btn-secondary" id="mdOpen">Abrir por JS</button>
<div class="modal fade" id="modalJs" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h1 class="modal-title fs-5">Por JS</h1>
        <button class="btn-close" data-bs-dismiss="modal" aria-label="Fechar"></button>
      </div>
      <div class="modal-body">Aberto com <code>bootstrap.Modal</code>.</div>
    </div>
  </div>
</div>
document.getElementById('mdOpen').addEventListener('click', function () {
  bootstrap.Modal.getOrCreateInstance(document.getElementById('modalJs')).show();
});
Tip

Para avisos rápidos sem escrever HTML, use CRO.alert, CRO.confirm e CRO.prompt (Diálogos).

Tamanhos extras e estático

modal-sm, modal-lg, modal-xl (e modal-fullscreen-sm-down...). Com data-bs-backdrop="static" o clique fora não fecha: o Bootstrap aplica modal-static e a janela "balança".
