btn-close vira o botão de sistema "fechar" 11×11 do jogo.

<button type="button" class="btn-close" aria-label="Fechar"></button>
<button type="button" class="btn-close" disabled aria-label="Fechar"></button>

Dentro de modal, alert, toast e offcanvas ele já aparece no lugar certo da barra de título.

Note

Sempre dê aria-label ao botão (o ícone não tem texto). Nativo do kit: cro-btn cro-btn--close e cro-sys-btn cro-sys-btn--close.

Versão branca

btn-close-white é para fundos escuros (por exemplo text-bg-dark):

<div class="p-2 bg-dark d-flex align-items-center gap-2 text-white">Fundo escuro <button type="button" class="btn-close btn-close-white" aria-label="Fechar"></button></div>
