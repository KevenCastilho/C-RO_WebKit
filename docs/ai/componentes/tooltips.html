Tooltips

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.

cro-* / is-* classes in this page
cro-tip

Dicas ao passar o mouse. No kit usam a "dica" do jogo (caixa amarela), sem seta.

<button type="button" class="btn btn-secondary" data-bs-toggle="tooltip" data-bs-title="Dica do kit">Em cima</button>
<button type="button" class="btn btn-secondary" data-bs-toggle="tooltip" data-bs-placement="right" data-bs-title="À direita">Direita</button>
<button type="button" class="btn btn-secondary" data-bs-toggle="tooltip" data-bs-placement="bottom" data-bs-title="Embaixo">Embaixo</button>
<a href="#" data-bs-toggle="tooltip" data-bs-title="Link com dica">Link com dica</a>
Warning

Tooltips precisam ser inicializados com new bootstrap.Tooltip(el).

Limitation

A dica do jogo não tem seta, então o tooltip do kit também não.

Dica do navegador (title)

O atributo title mostra a dica nativa (não estilizável), mas o cursor "mão com ?" do kit aparece sozinho:

<span title="Dica nativa do navegador">Passe o mouse (cursor ?)</span>

Nativo do kit

<span class="cro-tip" style="width:140px;height:40px;padding:6px">Dica do jogo</span>

Marcação gerada

O Bootstrap gera .tooltip > .tooltip-arrow + .tooltip-inner com a classe de posição bs-tooltip-top|bottom|start|end|auto. No kit a seta não é exibida e o tooltip-inner é a caixa de dica do jogo. Para personalizar, mire em .tooltip-inner (via data-bs-custom-class).
