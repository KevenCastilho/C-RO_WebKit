Card

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Componentes
Human version (rendered examples)
componentes/card.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Um card é uma janela completa do jogo: barra de título (card-header), corpo, rodapé. As partes só aparecem quando você as declara.

Exemplo

<div class="card" style="max-width:300px">
  <div class="card-header">Status</div>
  <div class="card-body"><h5 class="card-title">Poring</h5><p class="card-text">Nível 1, HP 50.</p></div>
  <div class="card-footer"><a href="#" class="btn btn-primary btn-sm">Atacar</a></div>
</div>

Só corpo (sem header)

<div class="card" style="max-width:300px"><div class="card-body">Um card simples, só com corpo.</div></div>

Listas e imagens

<div class="card" style="max-width:300px">
