Accordion

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Componentes
Human version (rendered examples)
componentes/accordion.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.
cro-* / is-* classes in this page
cro-tree

Painéis recolhíveis. No kit cada item vira uma pasta da árvore do jogo (aberta/fechada).

Exemplo

<div class="accordion" id="acEx" style="max-width:520px">
  <div class="accordion-item"><h2 class="accordion-header"><button class="accordion-button" type="button" data-bs-toggle="collapse" data-bs-target="#acc1" aria-expanded="true" aria-controls="acc1">Equipamentos</button></h2>
    <div id="acc1" class="accordion-collapse collapse show" data-bs-parent="#acEx"><div class="accordion-body">Espada, escudo e armadura.</div></div></div>
  <div class="accordion-item"><h2 class="accordion-header"><button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#acc2" aria-expanded="false" aria-controls="acc2">Consumíveis</button></h2>
    <div id="acc2" class="accordion-collapse collapse" data-bs-parent="#acEx"><div class="accordion-body">Poções e asas.</div></div></div>
  <div class="accordion-item"><h2 class="accordion-header"><button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#acc3" aria-expanded="false" aria-controls="acc3">Cartas</button></h2>
    <div id="acc3" class="accordion-collapse collapse" data-bs-parent="#acEx"><div class="accordion-body">Cartas de monstros.</div></div></div>
</div>

Sempre aberto

Remova data-bs-parent para que vários itens fiquem abertos ao mesmo tempo.

Nativo do kit: <details>

O mesmo visual vale para o elemento HTML details, sem JavaScript:

<ul class="cro-tree" role="tree" style="max-width:300px"><li><details open><summary>Pasta aberta</summary><ul><li>Arquivo A</li><li>Arquivo B</li></ul></details></li><li><details><summary>Pasta fechada</summary><ul><li>Arquivo C</li></ul></details></li></ul>

Flush

accordion-flush remove bordas e cantos para encaixar o accordion em outro contêiner:

<div class="accordion accordion-flush" id="acFl" style="max-width:420px"><div class="accordion-item"><h2 class="accordion-header"><button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#acfl1" aria-expanded="false">accordion-flush</button></h2><div id="acfl1" class="accordion-collapse collapse" data-bs-parent="#acFl"><div class="accordion-body">Sem bordas.</div></div></div></div>
