Dropdowns

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Componentes
Human version (rendered examples)
componentes/dropdowns.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Menus de contexto abertos por um botão. No kit usam o menu do jogo (lista com seleção azul).

Exemplo

<div class="dropdown">
  <button
    class="btn btn-secondary dropdown-toggle"
    type="button"
    data-bs-toggle="dropdown"
    aria-expanded="false">
    Ações
  </button>
  <ul class="dropdown-menu">
    <li>
      <h6 class="dropdown-header">Personagem</h6>
    </li>
    <li><a class="dropdown-item active" href="#">Atacar</a></li>
    <li><a class="dropdown-item" href="#">Falar</a></li>
    <li>
      <hr class="dropdown-divider">
    </li>
    <li><a class="dropdown-item disabled" href="#" aria-disabled="true">Ignorar</a></li>
  </ul>
</div>

Derived/invented (not in the original game)

O cabeçalho do dropdown (dropdown-header) é derivado; o jogo não tem menu com títulos.

Menu de contexto por JavaScript

Sem Bootstrap, CRO.menu(itens, x, y) abre o mesmo visual em qualquer ponto. Veja Diálogos.

  </ul>

Classes: dropstart, dropend, dropup, dropdown-center, dropup-center, dropdown-menu-start/end, dropdown-toggle-split, dropdown-item-text, dropdown-menu-dark.

Limitation

dropdown-menu-dark não escurece o menu: o menu do jogo é sempre claro e o kit vence o Bootstrap. É coerente com a decisão de não ter modo escuro.
