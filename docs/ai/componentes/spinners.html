Spinners

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section

componentes/spinners.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Indicadores de carregamento. Derivação mínima do kit; para "ocupado" no cursor use o relógio do jogo (automático).

<div class="spinner-border text-primary" role="status"><span class="visually-hidden">Carregando...</span></div>
<div class="spinner-border text-success" role="status"><span class="visually-hidden">Carregando...</span></div>
<div class="spinner-grow text-danger" role="status"><span class="visually-hidden">Carregando...</span></div>
<div class="spinner-border spinner-border-sm" role="status"><span class="visually-hidden">Carregando...</span></div>

Em botão

<button class="btn btn-primary" type="button" disabled><span class="spinner-border spinner-border-sm" aria-hidden="true"></span> Carregando...</button>
Tip

Marque a região com aria-busy="true" para que o cursor vire o Poring "progress" do jogo, e html[aria-busy=true] para o cursor de espera da página toda.

Tamanho pequeno do spinner "grow"

<div class="spinner-border spinner-border-sm text-danger" role="status"><span class="visually-hidden">Carregando...</span></div>
