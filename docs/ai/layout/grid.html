Grid

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.

Sistema de 12 colunas com flexbox. As classes row e col-* são as do Bootstrap, sem alteração.

Como funciona

  • Containers (.container) centralizam o conteúdo.
  • Linhas (.row) são grupos horizontais de colunas.
  • Colunas (.col, .col-6, .col-md-4...) somam até 12 por linha; o excedente quebra para a linha de baixo.
  • .g-* controla o espaçamento (gutter) entre colunas.
<div class="container-fluid">
  <div class="row">
    <div class="col"><div class="bd-demo-box">1 de 3</div></div>
    <div class="col"><div class="bd-demo-box">2 de 3</div></div>
    <div class="col"><div class="bd-demo-box">3 de 3</div></div>
  </div>
</div>

Larguras diferentes

<div class="row g-2 mb-2">
  <div class="col-8"><div class="bd-demo-box">col-8</div></div>
  <div class="col-4"><div class="bd-demo-box">col-4</div></div>
</div>
<div class="row g-2 mb-2">
  <div class="col-md-4"><div class="bd-demo-box">col-md-4</div></div>
  <div class="col-md-4"><div class="bd-demo-box">col-md-4</div></div>
  <div class="col-md-4"><div class="bd-demo-box">col-md-4</div></div>
</div>
<div class="row g-2">
  <div class="col-auto"><div class="bd-demo-box">col-auto</div></div>
  <div class="col"><div class="bd-demo-box">col (preenche)</div></div>
</div>

Colunas em janelas

O grid é ideal para montar formulários dentro de janelas do jogo:

<div class="card" style="max-width:520px">
  <div class="card-header">Criar personagem</div>
  <div class="card-body">
    <form class="row g-2">
      <div class="col-7"><label class="form-label" for="g-nome">Nome</label><input class="form-control" id="g-nome" value="Ana"></div>
      <div class="col-5"><label class="form-label" for="g-cl">Classe</label><select class="form-select" id="g-cl"><option>Espadachim</option><option>Mago</option></select></div>
      <div class="col-12"><button class="btn btn-primary" type="submit">Criar</button></div>
    </form>
  </div>
</div>
Note

Para o aninhamento, alinhamento e ordenação de colunas veja Colunas. Para espaçamento, Gutters.
