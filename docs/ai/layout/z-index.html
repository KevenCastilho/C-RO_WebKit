Z-index

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.

Camadas fixas do Bootstrap para componentes sobrepostos. O kit as mantém.

Escala

Camada z-index
dropdown 1000
sticky 1020
fixed 1030
offcanvas-backdrop 1040
offcanvas 1045
modal-backdrop 1050
modal 1055
popover 1070
tooltip 1080
toast 1090

Utilitários: z-n1, z-0, z-1, z-2, z-3.

<div
  class="position-absolute z-1 bd-demo-box"
  style="left:20px;top:20px;width:120px;height:60px;background:#cfe">
  z-1
</div>
<div
  class="position-absolute z-2 bd-demo-box"
  style="left:70px;top:50px;width:120px;height:60px;background:#fec">
  z-2
</div>
Note

Os diálogos CRO.alert/confirm/prompt usam <dialog> na camada superior (top layer) do navegador, acima de qualquer z-index.
