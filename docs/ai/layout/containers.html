Containers

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Layout
Human version (rendered examples)
layout/containers.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Containers centralizam e limitam a largura do conteúdo, exatamente como no Bootstrap.

Tipos

<div class="container">…</div>
<!-- largura máxima por breakpoint -->
<div class="container-sm">…</div>
<!-- 100% até sm, fixo a partir de sm -->
<div class="container-md">…</div>
<div class="container-lg">…</div>
<div class="container-xl">…</div>
<div class="container-xxl">…</div>
<div class="container-fluid">…</div>
<!-- sempre 100% -->
<div class="container-fluid">
  <div class="bd-demo-box">container-fluid (100%)</div>
</div>
<div class="container mt-2">
  <div class="bd-demo-box">container (limitado)</div>
</div>

Dentro de janelas do kit

Containers funcionam dentro de modal, card e cro-window. Eles só dependem da largura do pai.

<div class="card" style="max-width:420px">
  <div class="card-header">Janela</div>
  <div class="card-body">
    <div class="container-fluid">
      <div class="row">
        <div class="col">
          <div class="bd-demo-box">A</div>
        </div>
        <div class="col">
          <div class="bd-demo-box">B</div>
        </div>
      </div>
    </div>
  </div>
</div>
