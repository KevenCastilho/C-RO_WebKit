Breakpoints

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section

Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Os pontos de quebra responsivos são os do Bootstrap 5.3. O kit não altera nenhuma medida do grid.

Tabela

Breakpoint Sufixo Largura mínima Container máx.
Extra pequeno (nenhum) <576px 100%
Pequeno sm ≥576px 540px
Médio md ≥768px 720px
Grande lg ≥992px 960px
Extra grande xl ≥1200px 1140px
XXL xxl ≥1400px 1320px

Os sufixos valem para colunas (col-md-4), display (d-lg-none), flex, espaçamento, texto e demais utilitários responsivos.

Media queries

@media (min-width: 768px)  { /* md e acima */ }
@media (min-width: 992px)  { /* lg e acima */ }
@media (max-width: 575.98px) { /* só xs */ }
<div class="d-block d-md-none">
  <span class="badge text-bg-danger">Você está abaixo de md</span>
</div>
<div class="d-none d-md-block">
  <span class="badge text-bg-success">Você está em md ou maior</span>
</div>
Tip

Redimensione a janela do navegador para ver o exemplo trocar.

Note

O próprio kit usa container-type e media queries do Bootstrap onde precisa. A tela do jogo (800×600) não é um breakpoint do kit: o layout é fluido.
