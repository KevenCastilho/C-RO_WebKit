Reboot e elementos nus

Type
Native kit piece. Uses cro-* classes that belong to C-RO. They work with or without Bootstrap.

Conteúdo

Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

O kit estiliza os elementos HTML sem exigir classes. Um site de HTML puro já sai com a cara do jogo.

Como funciona

Os seletores de elemento usam :where() (especificidade 0). Assim:

  • Um <button> simples já parece um botão do jogo.
  • Qualquer classe sua, ou do Bootstrap, vence o estilo de elemento.
  • Se você escrever button { ... } no seu CSS, o seu vence.
<h1>Título h1</h1><h2>h2</h2><h3>h3</h3>
<p>Texto com <a href="#">link</a>, <b>negrito</b>, <i>itálico</i>, <mark>mark</mark>, <del>del</del>, <ins>ins</ins>, <code>code</code> e <kbd>Ctrl</kbd>.</p>
