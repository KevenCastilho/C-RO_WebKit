Cor e fundo

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Helpers
Human version (rendered examples)
helpers/cor-fundo.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Helpers text-bg-* definem fundo e cor de texto contrastante de uma vez. Usam as cores do tema do kit.

<div class="p-2 text-bg-primary">primary</div>
<div class="p-2 text-bg-secondary">secondary</div>
<div class="p-2 text-bg-success">success</div>
<div class="p-2 text-bg-danger">danger</div>
<div class="p-2 text-bg-warning">warning</div>
<div class="p-2 text-bg-info">info</div>
<div class="p-2 text-bg-light">light</div>
<div class="p-2 text-bg-dark">dark</div>

Funcionam também em card, modal-content, offcanvas e popover: os filhos herdam a cor do texto.

<div class="card text-bg-danger" style="width:200px"><div class="card-header">Perigo</div><div class="card-body">Corpo branco sobre fundo vermelho do tema.</div></div>
Note

Para só o fundo use bg-primary, bg-success...; só o texto: text-primary... Veja Fundo e Cores.
