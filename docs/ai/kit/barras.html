Barras de HP/SP/experiência, ícones de grupo e barras de botões.

Progress (cro-progress)

Defina o preenchimento com a variável --p (0–100).

<div style="max-width:260px">
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar" style="--p:70"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--orange" style="--p:60"></div>
  </div>
  <div class="cro-progress cro-mb-2">
    <div class="cro-progress__bar cro-progress__bar--red" style="--p:20"></div>
  </div>
  <div class="cro-progress">
    <div class="cro-progress__bar cro-progress__bar--blue" style="--p:90"></div>
  </div>
</div>
Note

Como é no jogo. A barra tem 85×8 px (o tamanho da janela Basic Info), é azul (HP e SP são ambos azuis) e fica vermelha só abaixo de 25% de vida. O texto "atual / máx" vai como texto comum abaixo ou ao lado da barra, nunca dentro dela. Use cro-progress--fluid (largura 100%) só quando o layout realmente pedir uma barra larga. As outras cores existem para barras de outros usos, não para HP.

Cores: --green, --blue, --cyan, --yellow, --orange, --red, --pink, --purple, --gray e --sp.

Barra de experiência (cro-exp)

<div class="cro-exp" style="--p:62;width:260px"></div>

Atualizar por JavaScript

<div class="cro-progress" style="width:260px">
  <div class="cro-progress__bar" id="hpbar" style="--p:100"></div>
</div>
<p class="mt-2"><button class="btn btn-secondary btn-sm" id="hpdown">Levar dano</button></p>
var hp = 100;
document.getElementById('hpdown').addEventListener('click', function () {
  hp = hp <= 15 ? 100 : hp - 15;
  CRO.bar(document.getElementById('hpbar'), hp);   // abaixo de 25% a barra fica vermelha
});
