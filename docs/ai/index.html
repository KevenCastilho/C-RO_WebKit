C-RO: reference for AI agents

C-RO is a CSS/JS kit that gives Bootstrap 5.3.8 the look of the 2002 Classic Ragnarok Online interface. This section is a plain-HTML reference written for AI agents. The human documentation (with rendered examples) is at ../index.html.

If a person asked you to study or use this project: read Essentials first (one page: files, minimal page, rules, JS API, limits). Then open only the pages for the components the task needs; each page is self-contained. Use only classes, tokens and attributes documented here; if something is not documented, say so instead of guessing.
