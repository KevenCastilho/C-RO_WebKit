Estados válido e inválido com as classes do Bootstrap e a pseudo-classe :user-invalid do navegador.

Classes is-valid e is-invalid

<div style="max-width:320px">
  <input class="form-control is-valid mb-1" value="válido">
  <input class="form-control is-invalid" value="inválido" aria-describedby="val-fb">
  <div id="val-fb" class="invalid-feedback">Informe um nome com 4 a 12 letras.</div>
</div>

Validação do navegador

Com novalidate e was-validated, o Bootstrap mostra válido/inválido conforme as regras HTML (required, pattern, type=email).

<form class="needs-validation" id="val-form" novalidate style="max-width:320px">
  <label class="form-label" for="val-nome">Nome</label>
  <input
    class="form-control mb-1"
    id="val-nome"
    required
    minlength="4"
    placeholder="mín. 4 letras">
  <div class="invalid-feedback">Mínimo de 4 letras.</div>
  <div class="valid-feedback">Ótimo!</div>
  <button class="btn btn-primary mt-2" type="submit">Validar</button>
</form>
var f = document.getElementById('val-form');
f.addEventListener('submit', function (e) {
  e.preventDefault();
  f.classList.add('was-validated');
});
Note

Os campos mostram o estado inválido do kit (--cro-invalid, derivado) também sem classes, via :user-invalid, depois que o usuário interage.

Balões de validação

valid-tooltip e invalid-tooltip mostram a mensagem em balão (dentro de um contêiner position-relative):

<div class="position-relative mb-5" style="max-width:300px">
  <input class="form-control is-invalid" value="x">
  <div class="invalid-tooltip">invalid-tooltip: valor inválido.</div>
</div>

Grupos de input com validação

Dentro de input-group, adicione has-validation para os cantos arredondados continuarem corretos ao mostrar invalid-feedback:

<div class="input-group has-validation">
  <span class="input-group-text">@</span>
  <input class="form-control is-invalid">
  <div class="invalid-feedback">Usuário já existe.</div>
</div>
