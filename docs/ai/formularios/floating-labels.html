Floating labels

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Formulários
Human version (rendered examples)
formularios/floating-labels.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

O rótulo flutua sobre o campo quando ele tem valor ou foco.

<div style="max-width:320px">
  <div class="form-floating mb-2"><input type="email" class="form-control" id="fl1" placeholder="nome@exemplo.com"><label for="fl1">E-mail</label></div>
  <div class="form-floating mb-2"><input type="password" class="form-control" id="fl2" placeholder="Senha"><label for="fl2">Senha</label></div>
  <div class="form-floating"><textarea class="form-control" id="fl3" placeholder="Mensagem" style="height:80px"></textarea><label for="fl3">Mensagem</label></div>
</div>
Note

O placeholder é obrigatório no Bootstrap para o rótulo flutuar. O kit esconde o placeholder real para não sobrepor o rótulo.
