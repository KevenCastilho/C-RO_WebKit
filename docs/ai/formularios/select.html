data-cro-* attributes in this page
data-cro-select

form-select mantém o select nativo. Com data-cro-select ele ganha o popup de opções do kit.

Padrão

<div style="max-width:300px"><select class="form-select" aria-label="Classe"><option selected>Escolha...</option><option value="1">Espadachim</option><option value="2">Mago</option><option value="3">Gatuno</option></select></div>

Tamanhos, múltiplo e desabilitado

<div class="row g-2" style="max-width:640px">
  <div class="col"><select class="form-select form-select-lg mb-1"><option>lg</option></select><select class="form-select form-select-sm"><option>sm</option></select></div>
  <div class="col"><select class="form-select" multiple size="3"><option>Poring</option><option selected>Lunatic</option><option>Fabre</option></select></div>
  <div class="col"><select class="form-select" disabled><option>Desabilitado</option></select></div>
</div>

Popup do kit (data-cro-select)

O popup do <select> é desenhado pelo sistema e o CSS não alcança. Para ter as opções no visual do jogo, adicione data-cro-select. O kit dispara input e change normalmente.

<div style="max-width:300px"><select class="form-select" data-cro-select aria-label="Classe"><option>Espadachim</option><option>Mago</option><option>Gatuno</option><option>Arqueiro</option></select></div>
// o select continua sendo o elemento de verdade: ouça 'change' como sempre
document.querySelectorAll('select[data-cro-select]').forEach(function (s) {
  s.addEventListener('change', function () { console.log('classe:', s.value); });
});
Note

Sem o atributo, o select segue 100% nativo (melhor para mobile).
