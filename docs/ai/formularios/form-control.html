Form control

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Formulários
Human version (rendered examples)
formularios/form-control.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Campos de texto, textarea, tamanhos, readonly, plaintext e arquivo.

Exemplo

<div style="max-width:380px">
  <label for="fc1" class="form-label">E-mail</label>
  <input type="email" class="form-control mb-2" id="fc1" placeholder="nome@exemplo.com">
  <label for="fc2" class="form-label">Texto longo</label>
  <textarea class="form-control" id="fc2" rows="3">Linha 1</textarea>
</div>

Tamanhos

<div style="max-width:380px">
  <input class="form-control form-control-lg mb-1" placeholder="form-control-lg">
  <input class="form-control mb-1" placeholder="padrão">
  <input class="form-control form-control-sm" placeholder="form-control-sm">
</div>

Readonly, plaintext e desabilitado

<div style="max-width:380px">
  <input class="form-control mb-1" value="somente leitura" readonly>
  <input class="form-control-plaintext mb-1" value="texto simples" readonly>
  <input class="form-control" value="desabilitado" disabled>
</div>

Arquivo e cor

<div style="max-width:380px">
  <input class="form-control mb-1" type="file">
  <input class="form-control mb-1" type="file" multiple>
  <input
    type="color"
    class="form-control form-control-color"
    value="#4569b9"
    title="Escolha uma cor">
</div>

Datalist

<div style="max-width:380px">
  <input class="form-control" list="fc-dl" placeholder="digite...">
  <datalist id="fc-dl">
    <option value="Poring">
  </datalist>
</div>
Limitation

A lista do datalist é nativa do navegador.

Rótulos em linha

col-form-label, col-form-label-sm e col-form-label-lg alinham rótulos com campos do mesmo tamanho em layouts horizontais (Layout de formulários).
