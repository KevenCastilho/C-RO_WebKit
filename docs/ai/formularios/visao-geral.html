Visão geral

Type
Bootstrap drop-in. Write standard Bootstrap 5.3.8 markup. The kit only changes the look; no new classes are needed.
Section
Formulários
Human version (rendered examples)
formularios/visao-geral.html
Prose language
Brazilian Portuguese. Code, class names and identifier tables are language-neutral.

Todos os controles de formulário do Bootstrap com o visual de campo do jogo: fundo cinza-claro, borda fina, rótulos azuis.

Exemplo

<form style="max-width:420px">
  <div class="mb-2"><label for="vg-email" class="form-label">E-mail</label><input type="email" class="form-control" id="vg-email" placeholder="nome@exemplo.com"></div>
  <div class="mb-2"><label for="vg-sel" class="form-label">Classe</label><select id="vg-sel" class="form-select"><option>Espadachim</option><option>Mago</option><option>Gatuno</option></select></div>
  <div class="mb-2"><label for="vg-msg" class="form-label">Mensagem</label><textarea class="form-control" id="vg-msg" rows="2"></textarea></div>
  <div class="form-check mb-2"><input class="form-check-input" type="checkbox" id="vg-ck" checked><label class="form-check-label" for="vg-ck">Lembrar de mim</label></div>
  <button class="btn btn-primary" type="submit">Enviar</button>
</form>

Dois jeitos de escrever

  1. Bootstrap: form-control, form-select, form-check-input...
  2. Nativo do kit: cro-input, cro-select, cro-textarea, cro-check, cro-field, cro-label. Veja Formulários cro-*.
  3. Elementos nus: sem classe nenhuma, o <input> já sai estilizado (Reboot).

Limitation

Os popups nativos de data, hora e cor continuam do navegador; o CSS só estiliza o campo.
