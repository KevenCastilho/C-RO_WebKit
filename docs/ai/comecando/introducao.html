Comece a usar o C-RO: um CSS, um JS, a marcação padrão do Bootstrap e a aparência do Ragnarok Online clássico.

Início rápido

  1. Copie c-ro-bs.min.css, c-ro-bs.min.js e a pasta fonts/ (ela precisa ficar ao lado do CSS) para o seu projeto.
  2. Linke o CSS no <head> e o JS antes do </body>.
  3. Escreva Bootstrap normalmente.
<link rel="stylesheet" href="../dist/c-ro-bs.min.css">
...
<script src="../dist/c-ro-bs.min.js"></script>

Pronto. Este é o seu primeiro componente:

<div class="card" style="max-width:320px">
  <div class="card-header">Status</div>
  <div class="card-body">
    <h5 class="card-title">Poring</h5>
    <p class="card-text">Nível 1. Muito fofo e muito gelatinoso.</p>
    <a href="#" class="btn btn-primary btn-sm">Atacar</a>
  </div>
</div>

Usar direto do GitHub

O repositório é https://github.com/KevenCastilho/C-RO_WebKit. Há duas formas de usar os arquivos dele:

  1. Baixar e copiar (recomendado). Em Code → Download ZIP, copie de dist/ os arquivos que você precisa, mais a pasta fonts/. É a única forma de travar a versão, porque o repositório não usa tags: a branch main pode mudar.
  2. Apontar para o GitHub Pages. Funciona sem copiar nada, mas o endereço sempre serve a versão atual da main:
<link rel="stylesheet" href="https://kevencastilho.github.io/C-RO_WebKit/dist/c-ro-bs.min.css">
<script src="https://kevencastilho.github.io/C-RO_WebKit/dist/c-ro-bs.min.js"></script>

O CSS carrega as fontes da pasta fonts/ que está ao lado dele, então elas vêm do mesmo endereço (.../dist/fonts/). Não use raw.githubusercontent.com: o GitHub serve esses arquivos como texto puro e o navegador recusa o CSS e o JS.

Limitation

Apontar para o Pages deixa a sua página dependente do GitHub estar no ar e de a main não mudar. Para produção, copie os arquivos.

Qual arquivo usar

Você quer... Use
Bootstrap com a cara do jogo (o caso comum) c-ro-bs.min.css + c-ro-bs.min.js
Só as classes cro-*, sem Bootstrap c-ro.min.css + c-ro.min.js
O mesmo, sem as peças específicas do jogo c-ro.lite.min.css + c-ro.min.js

Veja todos os arquivos em Download e arquivos.

Página inicial recomendada

<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Olá, mundo!</title>
    <link rel="stylesheet" href="c-ro-bs.min.css">
  </head>
  <body>
    <div class="container py-3">
      <h1>Olá, mundo!</h1>
      <button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#m">
        Abrir janela
      </button>
    </div>
    <div class="modal fade" id="m" tabindex="-1" aria-hidden="true">
      <div class="modal-dialog modal-dialog-centered">
        <div class="modal-content">
          <div class="modal-header">
            <h1 class="modal-title fs-5">Janela</h1>
            <button
              type="button"
              class="btn-close"
              data-bs-dismiss="modal"
              aria-label="Fechar"></button>
          </div>
          <div class="modal-body">
            Esta janela tem barra de título e botão de sistema do jogo.
          </div>
          <div class="modal-footer">
            <button class="btn btn-secondary" data-bs-dismiss="modal">Fechar</button>
          </div>
        </div>
      </div>
    </div>
    <script src="c-ro-bs.min.js"></script>
  </body>
</html>
Tip

Sirva os arquivos com gzip ou brotli. O CSS tem sprites pixel-exatos embutidos: ~1,2 MB minificado, ~150 KB comprimido.

Fonte

O kit carrega a Nimbus Sans (clone métrico livre da Helvetica, Regular e Bold, subconjunto Latin em woff2) da pasta fonts/, que precisa estar ao lado do CSS — ou ajuste o caminho no CSS. Ele não usa a Helvetica instalada no sistema: no Windows o sistema troca "Helvetica" por Arial.

Note

A Nimbus Sans é AGPL-3.0 (texto em fonts/COPYING-AGPL-3.0.txt). A Helvetica real é fonte comercial e não vem no kit; veja fonts/NOTICE-FONTS.txt para usá-la.
