Você já tem um site em Bootstrap 5? A migração é trocar dois arquivos. Veja o que muda no visual e o que fica igual.

Passo a passo

  1. Troque bootstrap.min.css por c-ro-bs.min.css (e leve a pasta fonts/ junto).
  2. Troque bootstrap.bundle.min.js por c-ro-bs.min.js.
  3. Remova a inicialização duplicada, se houver. O bundle já traz bootstrap global.
  4. Abra o site. Revise o que o jogo não tem (lista abaixo).
Tip

Não mude a marcação. O kit não cria classes novas para o que o Bootstrap já oferece.

O que pode precisar de ajuste

  • Alturas fixas: botões e campos do jogo têm altura própria (18–20px). Se o seu CSS fixava alturas, revise.
  • Tamanho de fonte: a base é 12px (como o jogo). Títulos seguem a escala do Bootstrap relativa a isso.
  • Customização de Sass: não há Sass para o consumidor. Cores do tema são compiladas no build (veja Customização).
  • Sombras e raios: o jogo tem bordas de 2–3px e quase nenhum arredondamento; rounded-* funciona, mas o visual fica fora do estilo.

Cursor e favicon

Ao migrar, todo o site passa a usar os cursores do Ragnarok. Se alguma parte precisa de outro cursor, declare cursor: no seu CSS (ele vence). O favicon do kit só entra se o site não declarar um.

Classes internas do Bootstrap (você não escreve)

O Bootstrap aplica estas classes sozinho durante transições e posicionamento; o kit as respeita e não as altera: collapsing, showing, hiding, carousel-item-next, carousel-item-prev, carousel-item-start, carousel-item-end, pointer-event, bs-tooltip-top, bs-tooltip-bottom, bs-tooltip-start, bs-tooltip-end, bs-tooltip-auto, bs-popover-top, bs-popover-bottom, bs-popover-start, bs-popover-end, bs-popover-auto, popover-arrow, popover-header, popover-body, modal-static (modal que balança ao clicar fora com data-bs-backdrop="static") e bi (ícones do Bootstrap Icons, não incluídos).

Variações por breakpoint que existem no Bootstrap e funcionam igual no kit: list-group-horizontal-lg, list-group-horizontal-xl, list-group-horizontal-xxl, navbar-expand-xl, navbar-expand-xxl, offcanvas-md, offcanvas-xl, offcanvas-xxl, table-responsive-md, table-responsive-lg, table-responsive-xl, table-responsive-xxl.
