As regras de convivência entre o kit e o Bootstrap, para você prever o resultado sem tentativa e erro.

A ideia

O C-RO é um tema completo do Bootstrap 5.3.8 com a linguagem visual da interface do Ragnarok Online clássico. Você escreve a marcação normal do Bootstrap; o CSS troca a aparência. O kit nunca pede classes novas para o que o Bootstrap já tem.

Camadas e precedência

@layer bootstrap;            /* 1. Bootstrap inteiro, dentro do layer */
/* 2. kit (fora de qualquer layer)   -> vence o Bootstrap */
/* 3. utilitários do Bootstrap (fora do layer), no fim */
/* 4. o CSS do SEU site (se vier depois) -> vence o kit */

Como o CSS "sem layer" vence qualquer layer, o kit sempre ganha do Bootstrap, mesmo com seletores mais fracos. E como os elementos HTML nus do kit usam :where() (especificidade zero), o seu CSS vence o kit sem precisar de !important.

Tip

Regra de ouro: quando houver conflito, o kit vence o Bootstrap, e você vence o kit.

Três tipos de aparência

<button class="btn btn-primary">Bootstrap (drop-in)</button>
<button class="cro-btn">Classe cro-* do kit</button>
<button>Elemento HTML nu</button>
  1. Drop-in Bootstrap — btn, card, modal... com a cara do jogo.
  2. Peças cro-* — para o que o Bootstrap não tem (janela, slot, árvore...). Funcionam com ou sem Bootstrap.
  3. Elementos nus — <button>, <input>, <table>, <h1>... já saem estilizados sem classe (veja Reboot).

Utilitários

Os utilitários do Bootstrap (d-flex, mb-3, text-center...) funcionam normalmente e ficam fora do layer. Só display e visibilidade usam !important (como no Bootstrap), para que d-none esconda de verdade mesmo quando o kit define display num componente.

Onde o jogo não tem equivalente

O Ragnarok clássico tem poucos componentes de UI. Para os que não existem lá (carousel, spinner, placeholder, breadcrumb, offcanvas, popover...), o kit deriva o visual a partir dos elementos reais e marca o item como DERIVADO ou INVENTADO. Veja Fidelidade.

O que o kit não faz

  • RTL: não suportado (a UI do Ragnarok não é RTL).
  • Modo escuro: fora da v1 (o jogo é claro).
  • Ele não tenta estilizar UI nativa do navegador que o CSS não alcança (popup de select sem data-cro-select, seletor de data/cor, barras de rolagem fora do WebKit...). Veja Navegadores e limites.
