    Tabelas

    Drop-in Bootstrap

    .table e variantes aplicam o visual de tabela do jogo.

    Básica#

    ItemQtdPreço
    Poção Vermelha1250 z
    Asa de Mosca560 z
    Asa de Borboleta1300 z
    HTML
    <table class="table">
  <thead><tr><th>Item</th><th>Qtd</th><th>Preço</th></tr></thead>
  <tbody>
    <tr><td>Poção Vermelha</td><td>12</td><td>50 z</td></tr>
    <tr><td>Asa de Mosca</td><td>5</td><td>60 z</td></tr>
    <tr><td>Asa de Borboleta</td><td>1</td><td>300 z</td></tr>
  </tbody>
</table>

    Variações#

    #NomeLv
    1Ana99
    2Bia50
    3Cris10
    4Dani1
    HTML
    <table class="table table-striped table-hover table-sm">
  <thead>
    <tr>
      <th>#</th>
      <th>Nome</th>
      <th>Lv</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Ana</td>
      <td>99</td>
    </tr>
    <tr>
      <td>2</td>
      <td>Bia</td>
      <td>50</td>
    </tr>
    <tr class="table-primary">
      <td>3</td>
      <td>Cris</td>
      <td>10</td>
    </tr>
    <tr class="table-danger">
      <td>4</td>
      <td>Dani</td>
      <td>1</td>
    </tr>
  </tbody>
</table>

    Classes de linha/célula contextuais (table-primary, table-success, table-danger...) usam as cores do Bootstrap.

    Responsiva#

    HTML
    <div class="table-responsive"><table class="table">…</table></div>

    Nativa do kit#

    Sem Bootstrap, a classe cro-table (ou o elemento <table> nu) tem o mesmo visual. Veja Árvore, menu e lista.

    Tabelas responsivas por breakpoint: table-responsive-sm, -md, -lg, -xl, -xxl (a rolagem horizontal só aparece abaixo do breakpoint).

    Nota

    table-dark mantém o fundo escuro do Bootstrap: é a única superfície escura do kit além de navbar-dark e text-bg-dark. Não há modo escuro geral (veja Navegadores e limites).
