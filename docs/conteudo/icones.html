    Ícones

    Extra do kit

    O kit traz os ícones pixel-exatos do jogo (cro-ico) e convive bem com Font Awesome, Lucide, Material Symbols e SVG próprio.

    Ícones do jogo#

    São CSS puro, sem imagem externa. Use <span class="cro-ico cro-ico--NOME"> (ou <button> quando clicável, com aria-label).

    HTML
    <span class="cro-ico cro-ico--lock" title="lock"></span>
<span class="cro-ico cro-ico--unlock" title="unlock"></span>
<span class="cro-ico cro-ico--folder" title="folder"></span>
<span class="cro-ico cro-ico--arw-up" title="arw-up"></span>
<span class="cro-ico cro-ico--arw-down" title="arw-down"></span>
<span class="cro-ico cro-ico--close" title="close"></span>
<span class="cro-ico cro-ico--chatmode" title="chatmode"></span>
<span class="cro-ico cro-ico--battle-opt" title="battle-opt"></span>

    Veja a lista completa em Ícones do jogo.

    Ícones de terceiros#

    O kit não embute Font Awesome, Lucide ou Material Symbols; ele garante que convivam. Os ícones modernos não têm o estilo Classic: para fidelidade use os cro-ico.

    Situação Como usar O que o kit faz
    Dentro de botão <button class="cro-btn"><svg …/>Salvar</button> ou <i class="fa-solid fa-floppy-disk"></i> ícone 12px, currentColor, 4px do texto, muda de cor com o botão
    SVG sem width/height (Lucide) <svg viewBox="0 0 24 24" stroke="currentColor" fill="none">… vira 1em (em vez de 300×150)
    Lista, menu, aba, título <span class="cro-icon-slot"><svg…/></span> (--11, --16) caixa fixa, herda a cor do estado
    <img> como ícone <img src="x.png" alt=""> continua inline (use .cro-block para bloco)
    HTML
    <button class="cro-btn">
  <svg
    viewBox="0 0 24 24"
    width="12"
    height="12"
    fill="none"
    stroke="currentColor"
    stroke-width="2">
    <path d="M5 12l5 5L20 7"/>
  </svg>
  Confirmar
</button>
<button class="btn btn-secondary">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <circle cx="12" cy="12" r="9"/>
  </svg>
  Círculo
</button>
