    Reboot e elementos nus

    Nativo do kit

    O kit estiliza os elementos HTML sem exigir classes. Um site de HTML puro já sai com a cara do jogo.

    Como funciona#

    Os seletores de elemento usam :where() (especificidade 0). Assim:

    • Um <button> simples já parece um botão do jogo.
    • Qualquer classe sua, ou do Bootstrap, vence o estilo de elemento.
    • Se você escrever button { ... } no seu CSS, o seu vence.
