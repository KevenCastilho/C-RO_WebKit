    Tipografia

    Drop-in Bootstrap

    Títulos, parágrafos, listas e utilitários de texto. A base é a Helvetica (Nimbus Sans) 12px, como no jogo.

    Títulos#

    h1. Título

    h2. Título#

    h3. Título#

    h4. Título

    h5. Título
    h6. Título
    HTML
    <h1>h1. Título</h1>
<h2>h2. Título</h2>
<h3>h3. Título</h3>
<h4>h4. Título</h4>
<h5>h5. Título</h5>
<h6>h6. Título</h6>

    Classes .h1–.h6 e .display-1–.display-6 dão o tamanho sem a semântica:

    Parece h3, mas é um parágrafo

    display-6

    HTML
    <p class="h3">Parece h3, mas é um parágrafo</p>
<p class="display-6">display-6</p>

    Marcador do kit (bolinha sys_base)#

    Toda <ul> solta (sem class nem role) usa como marcador a bolinha azul 11×11 do jogo (sys_base), no lugar do quadrado do HTML. A <ol> continua numerada. O marcador não é aplicado dentro de componentes que já têm visual próprio: árvore, menu, list-group, nav, paginação, breadcrumb, dropdown, abas e qualquer <nav>.

    Os estados são os mesmos do botão cro-sys-btn: repouso, hover (bolinha acesa), :active (acesa e um pouco mais escura), is-on/is-active/aria-current/aria-selected (acesa) e is-disabled/aria-disabled="true" (cinza, sem reagir ao mouse).

    • Item normal (passe o mouse)
    • Item com is-on
    • Item desabilitado
    • Item com filhos
      • Filho a
      • Filho b
    HTML
    <ul>
  <li>Item normal (passe o mouse)</li>
  <li class="is-on">Item com <code>is-on</code></li>
  <li aria-disabled="true">Item desabilitado</li>
  <li>Item com filhos
    <ul><li>Filho a</li><li>Filho b</li></ul>
  </li>
</ul>

    Para uma <ul> que tem class e ainda assim deve ter a bolinha, adicione cro-bullets. Para tirar a bolinha, use list-unstyled (ou qualquer class).

    • Lista com class própria
    • Mesma bolinha
    • Sem bolinha
    HTML
    <ul class="minha-lista cro-bullets">
  <li>Lista com class própria</li>
  <li>Mesma bolinha</li>
</ul>
<ul class="list-unstyled">
  <li>Sem bolinha</li>
</ul>
    Nota

    > A regra usa :where() (especificidade 0): um li::before { content: none } ou um list-style seu no CSS do projeto vence sem precisar de !important.

    Citações e abreviações#

    Uma frase marcante.

    Alguém em Fonte
    HTML
    HTML
    <blockquote class="blockquote">
  <p>Uma frase marcante.</p>
  <footer class="blockquote-footer">Alguém em <cite>Fonte</cite></footer>
</blockquote>
<abbr title="HyperText Markup Language">HTML</abbr>
    Nota

    Elementos com title e abbr ganham automaticamente o cursor "mão com ?" do jogo. Veja Estados automáticos do cursor.

    Abreviações#

    initialism deixa a abreviação em caixa pequena: <abbr class="initialism" title="HyperText Markup Language">HTML</abbr>.
